Rz ゲート (Z 軸回転 θ)

単一量子ビットへ e−iθZ/2 を適用する Z 軸まわりのパラメタ可変回転ゲート。 回路エディタ上では 40 × 40 px の cyan-400 角丸正方形に Geist Bold 由来の 2 文字グリフ "Rz" を中央配置する。 回転角 θ は配置後にパラメタ編集ポップオーバで決め、見た目では Rx / Ry と同じ 1 量子ビット回転ゲートの chrome を継承する。

★ 批評 · 全体所見
Rz 固有性は「Z / S / T / S† / T† / P の 6 兄弟をまとめあげる中心点」、§ 07 の Rz vs P 議論が本ページの核

配色 (§ 02) / ジオメトリ (§ 03) / グリッド配置 (§ 06 前半) は h-gate.html と完全に共通、 字形 2 文字グリフ (§ 04) / θ パラメタ編集 (§ 06 後半) は ry-gate.html と共通の論点なので、 本ページの全体所見はそれらを参照するに留め、Rz 固有の論点だけを以下に展開する。

Rz の固有性は 「Rotation 族で最も別名固定角が多い」こと: Rz(π) ∝ Z / Rz(π/2) ∝ S / Rz(−π/2) ∝ S† / Rz(π/4) ∝ T / Rz(−π/4) ∝ T†。 これに加えて P(θ) = eiθ/2 Rz(θ) という「大域位相だけ違う双子ゲート P」が 別 palette カードで存在する。Rx 族 (X / √X / Rx の 3 兄弟) / Ry 族 (Y / Ry の 2 兄弟) と比べて Rz 族は 7 兄弟と最大で、 ユーザーが「どれを置くか」の決定樹はもっとも複雑。これを § 07 の bullet 4 / 5 / 6 で 3 つに分けて書いているが、 関係図 (Venn / Tree / Matrix) として 1 枚にまとめる価値が高い。

★ 批評 · Top Opportunities
影響度の大きい改善候補 (Rz 固有のものを中心に)

  3. Rotation 族共通の論点は ry-gate.html へ集約 — 字形 2 文字グリフ / θ ポップオーバ primitive / 「θ を色に持たせない」判断 / Rotation 族親仕様化は Rz でも該当するが、本ページでは Ry を canonical として参照に留める (§ 02 / § 04 / § 06 参照)。

§ 01概要 (見た目と用途)

Rz は Z = Pauli-Z の連続版で、任意角 θ の ブロッホ球 Z 軸まわりの回転を表す。 行列は対角形 diag(e−iθ/2, eiθ/2) で、計算基底 |0⟩ / |1⟩ の 測定確率は変えずに 相対位相だけを θ だけ回す。固定角の Z / S / T / S† / T† と同じ仲間で、 θ = π で Rz = −iZ、θ = π/2 で S、θ = π/4 で T (いずれも大域位相を除く) と一致するため、これらの上位互換として 連続パラメタが必要な場面で使う。見た目では「固定角」「任意角」を別色にせず、 cyan-400 = ユニタリ操作ゲートという既存の色対応を守る。 Rz 固有情報は字形 "Rz" と説明文、そしてパラメタ編集ポップオーバの θ 値に閉じる。

★ 批評 · § 01 概要
「Z / S / T / S† / T† / P / Rz の 7 兄弟」が文章でしか提示されていない

概要 p 内に「θ = π で Rz = −iZ、θ = π/2 で S、θ = π/4 で T」と 3 つの対応が並んでいる。 これに加えて Rz(−π/2) ∝ S† / Rz(−π/4) ∝ T† / P(θ) = eiθ/2 Rz(θ) があり、合計 7 ゲートが Rz を中心に同心円的に並ぶ。Rx の 3 兄弟 (X / √X / Rx) や Ry の 2 兄弟 (Y / Ry) と比べて圧倒的に複雑で、文章だけでは関係を覚えきれない。

提案: § 01 末尾に小型の関係図 (Z 軸の dial 上に θ = 0 / π/4 / π/2 / π / −π/4 / −π/2 のマークを置き、それぞれに対応する 固定角ゲート名 I / T / S / Z / T† / S† をラベル) を置く。Rz は dial そのもの、P はラベルが半分ずれた版、として 1 枚で 全関係が見える。これは Rz ページ最大の差別化要素になる。

★ 批評 · § 04 字形 (Rz 固有)
2 文字グリフ全般の論点は ry-gate.html § 04 に集約、Rz 固有は「z は palette 上で唯一の対角字形」

Rotation 族共通の論点 (字形高さが H の 53 % に対し 33 %、kerning の出所、3× zoom の必要性、Rotation 族親仕様化) は ry-gate.html § 04 の批評を参照。本ページでは Rz 固有の論点だけ展開する。

  • "z" path M28 0V100L394 611H42V710H522V610L154 99H533V0Z は対角線が支配する字形 — H / X / Y / Z / S / T / Rx (R+x) / Ry (R+y) / Rz (R+z) と並べたとき、"z" の左上→右下の対角ストロークは palette 上で唯一。これは Rotation 族内の視覚的識別性に貢献するが、本仕様ではメリットとして言及されていない。
  • "z" の x オフセット 24.673 は Rx (23.724) / Ry (23.923) より約 0.75〜0.95 大きい — 本文には書かれているが、これは "z" の左側余白が "x" / "y" より広い字形特性に起因する。視覚中心 (グリフのインク重心) を本体中心に揃えた場合 "z" は右に寄るため、optical-center-aware なオフセットが Geist Bold で計算されている。これは「letter-spacing は族で揃えていない」という事実の言い換えで、Ry の批評で指摘した曖昧さがここでも露出している。
  • note の "z の上端 / 下端は R の x-height とほぼ揃う" — § 04 表の最後の行に書かれているが、"x-height" はラテン文字組版用語で、x 字形の高さを指す。"R" は capital なので x-height ではなく cap-height が正確 (Geist Bold では x-height < cap-height)。用語の誤用で、後で修正したほうがよい。
  • note の "Rx (R→x: 15.014) / Ry (R→y: 15.015) と比較して Rz では 15.014 と同等" — 「同等」とあるが、Rz の R→z 間隔は実際には 24.673 - 9.659 = 15.014、Rx は 23.724 - 8.710 = 15.014、Ry は 23.923 - 8.908 = 15.015 なので本当にほぼ同等。一方で R の絶対 x オフセット (Rx: 8.710 / Ry: 8.908 / Rz: 9.659) は族で差があり、これは "R + 第二字形" の bbox の中心が本体中心と揃うように、R の左 padding を字形ごとに変えているため。この内訳が本文では片方しか書かれていない。

§ 06回路グリッド上の配置と θ パラメタ編集

Rz ゲートは 1 本の量子ビットワイヤ上の単一スロットに置く。スロットは 56 × 56 px 等間隔、 本体 40 px は中央配置で上下左右に 8 px の余白を持つ。配置後にクリックすると θ 値編集ポップオーバが開く。

うっすら入っているスロット境界の ui 線は説明用で、実 UI には描画されない。 隣接スロットへ連続配置しても、本体間には 16 px の余白が残り、ホバー枠同士が重ならない。

θ パラメタ編集ポップオーバ (モック)

Rz は配置後に回転角 θ を編集する。ポップオーバは cell の右下から 8 px のオフセットで開き、 自由入力 (ラジアン / 数式) と π 系プリセット (0 / π/4 / π/2 / π / 3π/2) の併用を許す。 値編集中もゲート本体の色 / サイズは変えず、現在の θ はセル下に数値ラベル (例: π/2) として描く。

§ 07意味論と設計判断

  • Rx / Ry と同じ角丸正方形にする: Rz は文字グリフで識別する通常の 1 量子ビット回転ゲート。X 系 (X / Rx の塗りつぶし円) ではなく Z 系 (cyan-400 角丸正方形) の chrome を継承する
  • 2 文字グリフ "Rz" を採用する: 大文字 R で「Rotation」、小文字 z で「軸ラベル」を表す。Qiskit / Cirq / Quirk と一致するアカデミック表記。すべて大文字 "RZ" は palette の他のゲート (H / Y / Z / S / T) と並べたとき視覚的に重く、字形バランスが崩れる
  • 回転角 θ を色で表現しない: θ は連続パラメタなので色相 / 明度マッピングは不安定 (θ = π と θ = π + 0.001 が同色)。θ の現在値はセル下の数値ラベルとポップオーバ (§ 06) に閉じる
  • Rz(π) と Z を別カードとして残す: 数学的には大域位相を除いて等価だが、ハードウェア / 教育文脈では「Z = 固定 π 位相反転」「Rz = 連続パラメタ」と役割が違うため、palette でも UI でも別ゲートとして並べる
  • Rz(π/2) と S、Rz(π/4) と T を別カードとして残す: 同様に、S は π/2 固定位相、T は π/4 固定位相 (Clifford+T で universal) として使う場面があるため、Rz(π/2) / Rz(π/4) とは別アイコンを持つ
  • P (Phase θ) と別カードとして残す: P(θ) = eiθ/2 Rz(θ) で大域位相のみ違うが、P の行列は diag(1, eiθ) で |1⟩ にだけ位相を乗せる教科書的な形式。Rz は |0⟩ / |1⟩ に対称的 (e∓iθ/2) に位相を分配し、合成ハミルトニアン −Z/2 を生成子とする物理的な形式。役割の説明が異なるため、X (固定円形) と Rx (角丸正方形) のような 2 系列を持たない P (固定円形) と Rz (角丸正方形) の対応として並べる
  • stroke を持たない: 本体色 cyan-400 が wire (ui-2) や背景 (bg-2) と十分区別できるため、枠線は足さない
  • span = 1 固定: Rz は単一量子ビットだけに作用するため、表示ブロックや QFT のような span リサイズを持たない
★ 批評 · § 07 意味論と設計判断
Rz vs P の議論が bullet 6 に圧縮されており、Rz 最大の固有論点を捉えきれていない

bullet 6 (P(θ) = eiθ/2 Rz(θ) で大域位相のみ違うが、P と Rz を別カードに残す) は Rz 最大の固有判断で、 Rotation 族で P と直接対応する唯一のゲートが Rzであることを定義している。 にもかかわらず、bullet として書かれていて他の汎用論点 (角丸正方形 / 2 文字グリフ / stroke なし) と平等に並んでおり、 Rz 固有性が埋もれている。

  • P 行列: diag(1, eiθ) — |0⟩ は不変、|1⟩ にだけ位相 eiθ を乗せる「非対称形式」。教科書 / Qiskit / Quirk が採用。
  • Rz 行列: diag(e−iθ/2, eiθ/2) — |0⟩ / |1⟩ に対称に位相を分配する「対称形式」。生成子 −Z/2 が物理的に明確。
  • 差: 大域位相 eiθ/2 — 観測可能量は変わらないので、回路シミュレーションでは等価。ただし制御 (controlled-Rz / controlled-P) を作るときに結果が違う (controlled の場合、大域位相が相対位相になる) ため、UI 仕様としては別カードに残す価値がある。

bullet 6 末尾の「X (固定円形) と Rx (角丸正方形) のような 2 系列を持たない P (固定円形) と Rz (角丸正方形) の対応」 は本文として読みにくい (二重否定気味)。「P は X / √X のように固定角名で覚えるゲートで、Rz は連続パラメタ。 ただし P 自身は θ を取るのでP は固定 + 連続のハイブリッド」という整理のほうが明快。

補足: bullet 1 / 7 / 8 (角丸正方形 / stroke なし / span = 1) はユニタリゲート族共通、bullet 2 / 3 (2 文字グリフ / θ 不表現) は Rotation 族共通で、h-gate.html § 07 批評 / ry-gate.html § 07 批評と同じく「(a) 族共通 / (b) Rotation 共通 / (c) Rz 固有」の 階層化が必要。Rz 固有として残るのは bullet 4 / 5 / 6 (Z / S / T / P との関係) で、これが本ページの核。
