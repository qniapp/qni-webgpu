Rz ゲート (Z 軸回転 θ)

単一量子ビットへ e−iθZ/2 を適用する Z 軸まわりのパラメタ可変回転ゲート。 回路エディタ上では 40 × 40 px の cyan-400 角丸正方形に Geist Bold 由来の 2 文字グリフ "Rz" を中央配置する。 回転角 θ は配置後にパラメタ編集ポップオーバで決め、見た目では Rx / Ry と同じ 1 量子ビット回転ゲートの chrome を継承する。

§ 01概要 (見た目と用途)

Rz は Z = Pauli-Z の連続版で、任意角 θ の ブロッホ球 Z 軸まわりの回転を表す。 行列は対角形 diag(e−iθ/2, eiθ/2) で、計算基底 |0⟩ / |1⟩ の 測定確率は変えずに 相対位相だけを θ だけ回す。固定角の Z / S / T / S† / T† と同じ仲間で、 θ = π で Rz = −iZ、θ = π/2 で S、θ = π/4 で T (いずれも大域位相を除く) と一致するため、これらの上位互換として 連続パラメタが必要な場面で使う。見た目では「固定角」「任意角」を別色にせず、 cyan-400 = ユニタリ操作ゲートという既存の色対応を守る。 Rz 固有情報は字形 "Rz" と説明文、そしてパラメタ編集ポップオーバの θ 値に閉じる。

§ 04字形 (Rz)

中央字形は gate-palette.html の基準 SVG g-Rz と同じ path / transform を使う。 CSS のテキスト描画ではなく、palette 側で定義された "R" + "z" の 2 つのベクタ字形を 40 px 本体へ重ねる。 H / Y / Z / S / T が単一文字なのに対し、Rz は 大文字 R + 小文字 z の 2 字形でひと組。 Rx / Ry / 大文字 R 始まりのパラメタ可変ゲートと字形パターンを共有する。

§ 06回路グリッド上の配置と θ パラメタ編集

Rz ゲートは 1 本の量子ビットワイヤ上の単一スロットに置く。スロットは 56 × 56 px 等間隔、 本体 40 px は中央配置で上下左右に 8 px の余白を持つ。配置後にクリックすると θ 値編集ポップオーバが開く。

うっすら入っているスロット境界の ui 線は説明用で、実 UI には描画されない。 隣接スロットへ連続配置しても、本体間には 16 px の余白が残り、ホバー枠同士が重ならない。

θ パラメタ編集ポップオーバ (モック)

Rz は配置後に回転角 θ を編集する。ポップオーバは cell の右下から 8 px のオフセットで開き、 自由入力 (ラジアン / 数式) と π 系プリセット (0 / π/4 / π/2 / π / 3π/2) の併用を許す。 値編集中もゲート本体の色 / サイズは変えず、現在の θ はセル下に数値ラベル (例: π/2) として描く。

ポップオーバ自体の chrome (枠 / 影 / 角丸) はトーストや context menu と共通の primitive にそろえる予定 (別仕様で定義)。Rx / Ry / P も同じポップオーバを共有し、ラベル ("RX" / "RY" / "RZ" / "PHASE") とプリセット集合のみが差分。

§ 07意味論と設計判断

行列
Rz(θ) = diag(e−iθ/2, eiθ/2) = [[e−iθ/2, 0], [0, eiθ/2]]
基底状態
Rz(θ)|0⟩ = e−iθ/2|0⟩
Rz(θ)|1⟩ = eiθ/2|1⟩
計算基底の確率振幅は不変、相対位相だけが θ 回る。
ブロッホ球
Z 軸まわりの θ 回転。X-Y 平面ベクトルの偏角を θ シフトする。|0⟩ / |1⟩ は固定点。
関係
Rz(0) = I / Rz(π/4) ∝ T / Rz(π/2) ∝ S / Rz(π) = −iZ / Rz(2π) = −I
P(θ) = eiθ/2 Rz(θ) (大域位相のみ違う)
  • Rx / Ry と同じ角丸正方形にする: Rz は文字グリフで識別する通常の 1 量子ビット回転ゲート。X 系 (X / Rx の塗りつぶし円) ではなく Z 系 (cyan-400 角丸正方形) の chrome を継承する
  • 2 文字グリフ "Rz" を採用する: 大文字 R で「Rotation」、小文字 z で「軸ラベル」を表す。Qiskit / Cirq / Quirk と一致するアカデミック表記。すべて大文字 "RZ" は palette の他のゲート (H / Y / Z / S / T) と並べたとき視覚的に重く、字形バランスが崩れる
  • 回転角 θ を色で表現しない: θ は連続パラメタなので色相 / 明度マッピングは不安定 (θ = π と θ = π + 0.001 が同色)。θ の現在値はセル下の数値ラベルとポップオーバ (§ 06) に閉じる
  • Rz(π) と Z を別カードとして残す: 数学的には大域位相を除いて等価だが、ハードウェア / 教育文脈では「Z = 固定 π 位相反転」「Rz = 連続パラメタ」と役割が違うため、palette でも UI でも別ゲートとして並べる
  • Rz(π/2) と S、Rz(π/4) と T を別カードとして残す: 同様に、S は π/2 固定位相、T は π/4 固定位相 (Clifford+T で universal) として使う場面があるため、Rz(π/2) / Rz(π/4) とは別アイコンを持つ
  • P (Phase θ) と別カードとして残す: P(θ) = eiθ/2 Rz(θ) で大域位相のみ違うが、P の行列は diag(1, eiθ) で |1⟩ にだけ位相を乗せる教科書的な形式。Rz は |0⟩ / |1⟩ に対称的 (e∓iθ/2) に位相を分配し、合成ハミルトニアン −Z/2 を生成子とする物理的な形式。役割の説明が異なるため、X (固定円形) と Rx (角丸正方形) のような 2 系列を持たない P (固定円形) と Rz (角丸正方形) の対応として並べる
  • stroke を持たない: 本体色 cyan-400 が wire (ui-2) や背景 (bg-2) と十分区別できるため、枠線は足さない
  • span = 1 固定: Rz は単一量子ビットだけに作用するため、表示ブロックや QFT のような span リサイズを持たない
