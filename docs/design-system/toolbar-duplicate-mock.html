Toolbar — Duplicate icon

上部ツールバーのゴミ箱の右隣に Duplicate (Lucide copy) アイコンを追加する。 アクティブな回路の複製を作って active を切り替える ─ circuit ピッカーのサブメニューにある Duplicate と同じ動作を top-level でショートカット化する位置づけ。

§ 01 ツールバーの位置 — ゴミ箱の右

並びは picker → undo → redo → trash → duplicate → divider → run → spacer → Local|GPU。 Duplicate はゴミ箱と同じ「アクティブ回路に対する操作」グループに属するので、divider の左に置いて 実行 cluster とは分離する。

§ 02 アイコンの解剖

Lucide copy ─ 2 つの角丸矩形が部分的に重なる line-art。背景の矩形 (左上) + 前面の矩形 (右下、塗り抜き) で構成され、「もう 1 つ作る」のメタファーが明快。 Geist の他のアイコン (undo / redo / trash / play) と同じ 24×24 viewBox / stroke-2 / linecap & linejoin: round なので weight が完全に揃う。

partspec
source Lucide copy (lucide.dev/icons/copy)。Lucide は ISC ライセンスでそのままパス座標を写してよい。
viewBox 0 0 24 24 (他の toolbar アイコンと同じスケール)
shape 1 (前面) <rect x="9" y="9" width="13" height="13" rx="2" ry="2"/>
shape 2 (背面の L 字) <path d="M5 15H4a2 2 0 0 1-2-2V4a2 2 0 0 1 2-2h9a2 2 0 0 1 2 2v1"/>
描画 fill none、stroke currentColor、stroke-width 2、linecap / linejoin round。 ボタン内では 18×18 px で描く (他の tool アイコンと同じ)。
tooltip / a11y response.on_hover_text("Duplicate circuit") を付ける。Cmd/Ctrl+D は本 PR では割り当てない (将来別 PR で hotkey の検討)。

§ 03 実装仕様 (Codex 用リファレンス)

差分は render/toolbar.rs と app/circuit_library.rs のみ。

  1. 新規 ToolbarIcon::Copy を render/toolbar.rs の ToolbarIcon enum に追加。paint_icon の match 腕に Lucide copy のパス 2 本 (Rect (9,9)→(22,22) radius 2 と上 §02 の L 字 path) を paint_path で 順に描く。
  2. show_edit_utilities でゴミ箱と divider の間に挿入: 
    if icon_button(ui, colors, ToolbarIcon::Trash, true, "Clear circuit").clicked() {
    // ... existing ...
}
if icon_button(ui, colors, ToolbarIcon::Copy, true, "Duplicate circuit").clicked() {
    self.duplicate_active_circuit();
    ctx.request_repaint();
}
  3. action: QniApp::duplicate_active_circuit() を新規 (or 既存の CircuitLibrary::duplicate を呼ぶ薄いラッパー)。実装はサブメニューの Duplicate と同等: 
    impl CircuitLibrary {
    /// Insert a copy of the active entry right after it, with name
    /// suffix " (copy)" (or numbered " (copy 2)" / " (copy 3)" if a
    /// "(copy)" sibling already exists), and switch active to the
    /// new entry. Triggers `bump_updated_at()`.
    pub(crate) fn duplicate_active(&mut self) -> CircuitId { ... }
}
    既に submenu 用に同等のロジックが居れば、それを共有する形で OK。
  4. サイズ / 色 は他の tool ボタンと完全に同じ: 32×32 px ボタン、18×18 px icon、stroke 2、tx-2 idle、tx hover、tx-3 disabled。 hover bg = ui。kebab style の "color だけ濃く" は適用しない (これは行内の kebab 専用ルール、ツールバーの通常 tool は bg + color 両方変える)。
  5. disabled 条件: 通常時は always enabled (active 回路は常に存在するので)。 将来 active が null になるエッジケースが出てきたら disable する想定だが、本 PR では考慮不要。
  6. テスト: tests/egui-web-toolbar-duplicate.spec.ts を新規:
    ・Duplicate ボタンクリック → 新 entry が active 直後に追加され active が切り替わる
    ・連続クリックで ... (copy) → (copy 2) → (copy 3) のように suffix が増える
    ・既存 snapshot は toolbar アイコンが 1 個増えるので diff → cargo insta review で accept

Acceptance

  1. ツールバーのゴミ箱の右隣に Lucide copy アイコンが追加され、サイズ / 色 / hover 挙動が他の tool ボタンと一致。
  2. クリックで active 回路の複製が picker entries の active 直後に挿入され、新 entry が active になる。
  3. 複製の名前は "{元} (copy)"、すでに同名がいるなら (copy 2) など連番。
  4. tooltip "Duplicate circuit" がホバーで出る。
  5. divider は引き続き trash と Duplicate の右に置く (= edit cluster と execute cluster の境界は変わらない)。
  6. cargo clippy --target wasm32-unknown-unknown --all-targets -- -D warnings 通過、cargo fmt --check クリーン、cargo insta test → review で accept。
