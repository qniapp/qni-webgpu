スペーシング

余白 (padding / margin / gap / row pitch) と border-radius はすべて Tailwind 4px 倍数スケール に揃える。px-3.5 (14px) などスケール外サイズや、5px / 10px のような独自値は 使わない。スケールに馴染まないときはコンポーネント側の設計を見直す。

§ 014px 倍数スケール

実際にこのドキュメントセットで使う段階を列挙。バーは実寸 (1px = 1px) で描いている。 Tailwind には間の階調 (spacing-1.5 = 6 / spacing-2.5 = 10 / spacing-7 = 28 など) もあるが、qni-webgpu では基本 4px / 8px / 12px / 16px / 20px / 24px / 32px / 40px / 48px / 56px / 64px / 96px を 使い、間の階調は採用しない。

spacing-1 4 px

最小単位 (text-xs 内段間 / pill 縦寄せ)

spacing-2 8 px

card 内段間 / 段落 margin / spec-card 内 gap

spacing-3 12 px

spec-card grid gap / h2 下 margin / breadcrumb 隣接間隔

spacing-4 16 px

spec-card padding (vertical) / footer 内段間 / note 下 margin

spacing-5 20 px

spec-card padding (horizontal) / card 内 padding

spacing-6 24 px

section.block padding (vertical) / card padding (horizontal) / footer padding

spacing-8 32 px

.page / section.block 左右 padding / breadcrumb 左右 padding

spacing-10 40 px

ゲート本体 / card 大きめ余白

spacing-12 48 px

セクション間の大ブレイク

spacing-14 56 px

.page top padding / 量子ビットピッチ / footer top margin

spacing-16 64 px

大型カード height / 画像レール height

spacing-18 72 px

.spec-card .preview height (サムネ枠)

spacing-24 96 px

body bottom padding (フッタ下余白)

§ 02用途別カテゴリ

同じ 4px スケールでも、padding / gap / margin / border-radius によって採用しやすい値が変わる。 新規セレクタを追加するときは、まず近い用途のカテゴリを見て既存値を再利用する。

padding (内側余白)

  • 1px 6px インラインコード code
  • 0 8px pill
  • 12px 16px .space-row / .cd-popup
  • 16px 20px .spec-card / .card
  • 20px 24px .card 内寄り / 大カード
  • 24px 32px section.block / footer / breadcrumb
  • 56px 32px .page top padding

gap (要素間隔)

  • 4px 行内ラベル / mono pill
  • 8px .spec-card 内段 / breadcrumb / legend
  • 12px .spec-grid / h2 内番号
  • 16px .swatch / .type-spec / footer
  • 24px .stage / link-list 列

margin (外側余白)

  • 0 0 8px .page-lede / 段落の下
  • 0 0 12px .card h3 / section.block > h2
  • 0 0 16px .card / .note 下
  • 12px 0 8px page-title 上下
  • 56px auto 0 footer top

border-radius (角丸)

  • 2px .space-row .bar
  • 4px インラインコード / table セル
  • 6px pre.code / lock-button
  • 8px .preview / .space-row
  • 12px .spec-card / .card
  • 14px .card (汎用)
  • 999px pill (完全な楕円)

§ 03アプリ側スペーシング

回路グリッド / ゲートサイズ / 余白も、Tailwind の 4px 倍数スケールに揃える。 アプリ側は本表の値を参照し、独自のスケール外寸法を追加しない。

項目値Tailwind 名使い所
ゲート本体40 pxspacing-101 量子ビットセル
量子ビット行間56 pxspacing-14回路上下のピッチ
ゲート列ピッチ56 pxspacing-14回路左右の刻み
ワイヤ余白——左右のワイヤ余白
