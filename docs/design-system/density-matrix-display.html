密度行列表示ブロック

span 内の量子ビットを測定せずに、局所的な混合状態 (reduced density matrix) ρ = Trrest(|ψ⟩⟨ψ|) を可視化する密度行列表示ブロック (表示ブロック の定義は AGENTS.md 用語集と design-system §04 参照)。 振幅表示ブロックが α = re + i·im 1 本を 2span セルで描くのに対し、本表示ブロックは ρij の 2span × 2span 全成分 を行列状に描く。 対角成分は 各測定結果の確率 P(|i⟩) = ρii、非対角成分は coupling / coherence ρij (絶対値 = 大きさ、偏角 = 相対位相)。 span 上限は 8 量子ビット (span 8 は 65 536 セルの正方行列で、ヒートマップとして読む)。 配色 (blue-200 fill / blue-400 disk border / tx-2 outline / tx needle) は 振幅円 プリミティブに従い、振幅表示ブロック / 状態ベクトルパネルと完全に揃える。 密度行列表示ブロックの見た目を、Flexoki の表示ブロックとして定義する。本番表示は本ページの視覚仕様に従う。 実装上の契約は 密度行列表示ブロック実装仕様 に分ける。

§ 01 概要 (見た目と用途)

span 内の量子ビットの縮約密度行列 ρ (対角 = 確率 / 非対角 = coupling) を 2span × 2span 行列で可視化する表示ブロック。混合状態 / もつれの度合いを 1 枚で読み取れる。 下のモックで「シンプルな span 1」と「典型的な span 2 (Bell)」の見た目を確認できる。

§ 02 サイズ別の見た目 (1〜8 量子ビット、動くモック)

span 1〜8 の代表的な reduced density matrix を並べた参考レンダリング。matrix 寸法は n × n (n = 2span) の正方行列、本体寸法は size_px = 56 × span − 16 px の正方形 (確率表示ブロックの高さ公式と一致、振幅表示ブロックの幅 / 高さ公式とも対称)。 cell 寸法 (cellPx = size_px / n) は span 3 以降で急速に縮む: span 1 で 20 px、span 4 で 13 px、span 5 で 8.25 px、span 7 で 2.94 px、span 8 で 1.69 px。 cellPx に応じてレイヤを段階的に省略する (§ 06): cellPx ≥ 12 = outline + disk + needle / cellPx ∈ [3, 12) = outline + disk (needle 省略) / cellPx < 3 = heatmap (mag を alpha に潰す dense mode)。 対角 / 非対角ともに outline 円 + magnitude disk で描き、disk 半径は対角なら ρii (= 確率)、非対角なら |ρij|。対角は実数 (位相 0) なので needle のみ省略する。 各セルにマウスを乗せると、対角は Probability of |k⟩、非対角は Coupling of |row⟩ to ⟨col| をポップオーバーで表示する。

§ 03 パレットアイコン (mini preview)

パレットに並ぶ DensityMatrixDisplay アイコンは 40 × 40 px の静的 mini preview。 2×2 行列 (= span 1) を 純粋 |+⟩⟨+| の密度行列 として描く: 4 セルすべてに 0.5 半径の magnitude disk + outline 円、非対角 2 セルだけは追加で真上 needle (実数なので位相 0 = 真上)。 「対角 / 非対角ともに disk、非対角だけ needle が立つ」という本表示ブロックの統一されたセル描画を 1 アイコン内で提示し、密度行列特有の行列 (matrix) 形状を視認させる。 アイコン自体の外側に四角枠は描かず、4 つの円だけで密度行列表示ブロックだと分かるようにする。円周の外端はセル境界から 1.5 px だけ内側に置き、hover 枠と重ならない範囲で最大化する。 ホバー時は外側のホバー枠だけ表示 (静的なので個別 cell ポップオーバーは出さない)。

§ 06 セル描画モデル (全セル統一、対角は needle のみ省略)

密度行列表示を Flexoki + 振幅表示ブロックの視覚言語へ揃える。 対角 / 非対角ともに同じ「outline 円 + magnitude disk」レイヤで描き、対角だけ needle を省くのがポイント。これにより:

  • 対角セル ρii = 実数の確率 P(|i⟩) ∈ [0, 1]。 outline 円 + magnitude disk の 2 層で描く。 disk 半径 = ρii × inner_radius (= P × inner_radius)、半径ゼロ (P = 0) なら disk を描かない。 needle は描かない: 対角は常に実数 (位相 0) なので needle が真上を向くだけになり情報量を持たず、視覚的ノイズになる。非対角と同じ disk 表現で統一する (対角セルだけは確率の値を disk の半径として読む)。
  • 非対角セル ρij (i ≠ j) = 複素数の coupling。 振幅表示ブロックと同じ outline 円 + magnitude disk + disk 境界線 + phase needle の 4 層で描く。 mag = |ρij|、phase = arg(ρij)。 disk 半径 = mag × inner_radius、needle 方向 = (−sin(phase), −cos(phase)) で真上が phase 0。 境界線 / 配色は振幅表示ブロックの規約に従う (amplitude-display.html § 06 と完全共有)。
  • Hermitian 性 — 密度行列は ρij = conj(ρji) なので、上三角と下三角は位相が反転した対称。表示としても自動的に左下と右上の needle が鏡像になるため、ユーザーは行列の片側を読むだけで全体が読める。対角は実数 (虚部 0) なので Hermitian 性も自動的に満たされる。

対角と非対角のスケール差: 対角セルは確率 ρii ∈ [0, 1]、非対角セルは結合 |ρij| ≤ √(ρiiρjj) ≤ 0.5 を半径として描く。 同じ disk 表現に統一すると、振幅表示ブロック / 状態ベクトルパネルと読み方を共有できる一方で、対角セルの disk が視覚的に大きくなりやすい。 本仕様ではこのトレードオフを受け入れ、対角 = disk のみ、非対角 = disk + needle の違いで意味を分ける。

(1) back fill — セル背景。通常時は bg (#FFFCF0)。drag preview 中は matrix 外周のみ purple-600 に差し替え、内部の cell 描画 (outline / disk / needle) は通常時のまま
(2) outline 円 (全セル) — セル中央、半径 = cellPx/2 − stroke/2 − 1.5 px。stroke は振幅表示ブロックに合わせ、cellPx ≥ 24 で 2 px、それ未満で 1 px。円周 stroke の外端をセル境界から 1.5 px 内側に置き、matrix 外枠と重ならない範囲で最大化する。描画条件: cellPx ≥ 3。mag > 1e-6 なら tx-2、≈ 0 なら ui-2。cell hover 時は outline 円を purple-400 に置き換える (振幅表示ブロックと同様)
(3) magnitude disk (全セル) — 中心 = セル中心、半径 = |ρij| × inner_radius。fill = blue-200 + inset 1 px blue-400 境界線。閾値: r > 0.3 で fill、r ≥ 1.5 で stroke も追加。対角は実部 = 確率 = 半径として描かれる
(4) phase needle (非対角のみ) — セル中心から方向 (−sin(phase), −cos(phase)) へ inner_radius の線分。tx stroke。描画条件: cellPx ≥ 12 かつ i ≠ j。対角は実数で位相 0 なので常に省略
(5) 外枠 — matrix 全体の外枠だけを ui-2 1 px で描く。cell 間の縦横区切り線は描かず、振幅表示ブロックと同じ円の余白でセル境界を読ませる

本仕様は対角も非対角と同じ disk 表現に統一する。理由は (a) 1 つの行列内に「塗りバー + 円」の 2 種類の見た目が並ぶと視線が分散する、(b) 振幅表示ブロック / 状態ベクトルパネルが既に「disk = 確率の大きさ、needle = 位相」の語彙を確立しているので、密度行列もそれに乗せたほうが学習コストが低い、(c) 対角は実数なので needle を省くだけで「確率 = 円」と「coupling = 円 + needle」の差が自然に出る。 log 強調用の補助円は disk と冗長 (disk が小さくても outline 円が常に視認できる) なので不採用。小さい coupling は magnitude disk の大きさだけで表現し、ロガリズム強調はポップオーバーの log P: ... dB 数値に集約する (§ 08)。

heatmap モード (cellPx < 3、span 7〜8)

cellPx が 3 px 未満では outline 円 / disk / needle が視覚的に潰れる。 各セルを 1 つの矩形塗りに潰し、alpha = √(|ρij|) で濃淡を出す:

  • 対角 / 非対角の区別はせず、全セルに blue-200 を √スケール alpha で塗る
  • matrix 全体の外枠だけは ui-2 1 px で残す。cell 間 grid は描かない
  • セルホバーは引き続き有効: purple-400 2 px の正方形の枠を描く (ヒートマップでは outline 円が無いため、振幅表示ブロックの「outline 円を purple-400 で置換」ではなくセル矩形の purple の枠を採用)
  • 位相情報はヒートマップでは消える: span 7〜8 ではポップオーバーだけが phase の供給源になる (セルホバー必須)

測定済み量子ビットの見た目

span 内に測定済み wire が含まれる列では、測定済みビットが異なる (row, col) ペアの非対角成分を 0 として表示する。 視覚的には、測定済み wire 由来の非対角列 / 行が消えて、対角の塊が残る。これは「測定後の古典化された状態」と「未測定の量子重ね合わせ」の境界を hover 抜きで見分ける手がかりになる。 計算順序は本ページの GPU-only 条件と、表示ブロックごとの出力要求に従う。

§ 07 実行前プレースホルダ (シミュレーション未実行の状態)

回路に密度行列表示ブロックを配置しただけで、まだシミュレーション (▶ Run) を実行していない段階で表示する仮の見た目。 行列値がまだ存在しない段階でもセル領域が真っ白に抜けて見えないよう、この空白を 「実行待ちであることを伝えるプレースホルダ」 として明示的にデザインする。 振幅表示ブロック (amplitude-display.html § 02) / 確率表示ブロック (probability-display.html § 02) と同じ配色コンベンションに従う。

  • 背景 (placeholder fill) — purple-100 (#ECE1F3) の薄い紫で matrix 全体を塗る。本デザインシステムでは紫を「未確定 / 進行中」に充てており (drag preview = purple-600、ホバー枠 = purple-400)、実行前の ρ も「0 (赤系) と 1 (青系) の中間に位置する未確定な値」として同じ紫系統で表す。色相は drag/hover で使う濃い紫よりさらに淡くし、「進行中アクション」と「結果待ち静止状態」を区別する
  • cell 構造ガイド — cell 間の grid は引かない。通常時と同じく、matrix 外枠だけで表示ブロックの領域を示す
  • outline 円 / disk / needle — 描かない。ρ の値が無いので「対角の確率」も「非対角の coupling」も意味を持たない
  • 外枠 — 通常時と同じ ui-2 1 px の外枠を引く
  • ホバー / ポップオーバー — 実行前はセル単位ポップオーバーを出さない (表示すべき数値が無い)。表示ブロック全体のホバー枠 (purple-400 4 px) は通常時と同じく出し、リサイズハンドルは端ごとの表示可否判定に従う
  • 遷移 — Run 結果が届いたフレームでプレースホルダ層 (薄紫背景 + 外枠) から通常の probability + disk + needle 描画へ即時に切り替える。150 ms ease-out のクロスフェードは将来の改善候補

§ 08 ホバー / ポップオーバー

セルホバー時の詳細表示は、共通 ポップオーバー の吹き出し型外装を使う。 対角セルは確率、非対角セルは結合を表示し、外装・tail・影・画面端反転の規約は 密度行列表示ポップオーバー仕様を正とする。 このページではセルホバー時に本体側へ出る強調枠だけを定義する。

セルホバー時の枠

  • 行列モード — 対象セルの outline 円周を purple-400 2 px に置き換える。対角 / 非対角ともに同じ outline 円を持つので扱いが統一される。行列全体のホバー枠はセルホバー中は消す (振幅表示ブロックの方針と同じ)
  • ヒートマップモード — セルが小さすぎて outline 円が無いので、セル領域の正方形の枠を purple-400 2 px で囲む

§ 09 リサイズハンドル (span 1〜8)

振幅表示ブロック / 確率表示ブロックの上下ハンドルとクロム仕様は完全に共有する (amplitude-display.html § 05 のリサイズハンドル節 / probability-display.html § 12 参照)。 ハンドル単独の挙動だけ要点を再掲する:

  • 配置 — matrix の上下中央に 1 つずつ。top / bottom: −12 px (4 px ホバー枠 + 2 px の背景の空き + 6 px 高さ の合計 12 px 外側)
  • 幅 — JS で canvas 幅 (size_px) の 60% に動的にスケール、min 24 px (上限なし、span 8 = 432 px なら handle 幅 ≈ 259 px)
  • 初期状態 — opacity: 0、ホストホバー時に表示可否判定を通った端だけが奥から飛び出してくるマイクロインタラクション (フェードイン + 軽いバウンス: scale(0.7) → scale(1) in 250 ms cubic-bezier(0.34, 1.56, 0.64, 1))
  • default — cyan-400 ベース (ホバー枠 purple-400 と別色族で「リングの突起 ?」誤認を回避)
  • 個別 hover — cyan-600 + scale(1.15)、cursor は ns-resize
  • active drag — cyan-600 + scale(1.25)、固定
  • span 範囲 — ドラッグの上限は span 8、下限は span 1。上下それぞれの表示可否とドラッグ停止条件は resize-handle.html § 06 に従い、span 1 では空いている端だけ表示し、他の回路要素に重なる手前で止める
  • 左右ハンドルなし — width は span の関数 (56 × span − 16) なので独立した width handle は不要。高さハンドルの変更で同時に幅も変わる正方形リサイズ
