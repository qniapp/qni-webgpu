タイポグラフィ

フォントは Geist (本文) と Geist Mono (コード / 数値 / ラベル) の 2 系のみ。 日本語は Hiragino Kaku Gothic ProN / Yu Gothic / system-ui にフォールバック。 サイズは Tailwind text-* スケール (text-xs 12 / text-sm 14 / text-base 16 / text-lg 18 / text-xl 20 / text-2xl 24 / text-3xl 30) のみ使う。 13px / 11px / 9px などスケール外サイズは 使わない。

§ 01フォントファミリー

本文系 / 等幅系の 2 系で完結させる。等幅系は数値・ラベル・code 要素 / シリアル ID など、 桁揃え (tabular-nums) や ASCII の比率を保ちたい用途に限定する。

§ 02サイズスケール (Tailwind text-*)

実際にこのドキュメントセットで使うサイズだけ列挙。サンプルはそのサイズ・行間で表示。 line-height は対応する Tailwind 既定 (text-xs → 16 / text-sm → 20 / text-base → 24 / text-2xl → 32 / text-3xl → 36) を使う。
