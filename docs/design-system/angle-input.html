角度入力 UI 仕様

Phase / Rx / Ry / Rz の角度文字列をインライン編集するための仕様。ワイヤ間隔とゲート列幅を変えず、角度ラベルだけを編集欄へ置き換える配置とふるまいを定義する。

01. インライン入力

特徴

  • 角度ラベルは 12px の等幅フォント、Flexoki tx で表示する。
  • クリック後 680ms、またはホバー開始から 680ms は何も表示せず、その後 120ms で角度文字列の下線を一段薄い黒へフェードインする。
  • 上側ラベルは対象ゲートの上端、下側ラベルは対象ゲートの下端 + 2px を基準にする。接続方向が top && bottom のときだけ背景ふちどりを使う。
  • ワイヤ間隔は固定なので、表示ブロックや複数ワイヤゲートの高さを押し広げない。
  • 入力欄はゲート列幅を変えないため、ゲートは下にずれない。

02. 不正入力の扱い

A. 入力中

Enter または外側クリックで確定を試みる。入力中は警告を出さず、通常のインライン編集欄のままにする。

B. 確定後

角度ラベル

不正な値は保存せず、編集前の角度に戻す。エラーバッジは出さない。

03. 入力規則

  • 1/2 は π/2 と表示する。1 は π、0 は 0 と表示する。
  • 2/4、-2/-4 のように約分できる分数は π/2 に正規化して保存する。
  • -1/2 は -π/2 と表示し、そのまま保存する。
  • abc、1//2、分母が 0 の値は保存せず、編集前の角度へ戻す。
  • 0.5π のような小数係数は有限値のときだけ保存し、そのまま表示する。
