Lock / Unlock ボタン

回路ピッカーを Example Circuits と My Circuits の 2 セクションに分ける際に必要な 「現在の回路が編集可能か」を示すトグルボタン。複製アイコンの直右に追加し、 Lucide lock / lock-open を outline で 24×24 → 18 px に描画する。 既存トップバーの規格と完全に揃える。

方針 (案 B の改訂): sample-circuit-options.html 案 B の「Example 選択時に自動で My Circuits へ複製してアクティブ化」は、 サイレントなフォークでユーザが知らぬ間に別物を編集している混乱を生むため採用しない。 本仕様では Example は直接アクティブ化し、トップバーの lock ボタンを tx-3 disabled で固定表示することで「これは編集できない、Duplicate して編集」を明示的に伝える。 Duplicate を明示的に押した時だけ My Circuits にコピーが作られる。

§ 01 動くモック

実物相当のトップバーと回路ピッカー。回路名をクリックすると Example Circuits / My Circuits のドロップダウンが開く。 Example を選ぶと lock は固定 (tx-3 disabled)、 My を選ぶと lock がトグル可能 (unlocked: 透明背景 / locked: ui 背景ピル)。 ロックボタンにマウスを乗せるとツールチップが状態に応じて切り替わる。

§ 03 3 つの状態

「現在の回路の origin」と「lock フラグ」の組合せで決まる 3 状態。 アイコン形 (open ↔ closed) と背景 (透明 / ui ピル / 透明 + disabled 色) の 2 系統で区別する。 色が判別できない環境でも形だけで unlocked / locked が伝わる。

§ 04 編集禁止の不変条件

locked = 「その回路の内容や名前を書き換える操作を一切受け付けない」。 Example Circuits は常時 locked、My Circuits はユーザが lock ボタンで明示的に切り替え可能。 locked は回路内容と名前の両方を凍結する (ゲート編集 / ゲート配置 / Clear / Undo/Redo / 実行中の URL 適用 / Rename / Delete を抑止)。 一方、回路内容や名前を書き換えない操作、または unlock のためのメタ情報更新は locked でも通す: Select (active 切替) / Duplicate / Create new circuit / My 内 reorder (順序は別管理) / locked My の lock toggle (ロック状態のメタ情報更新で unlock 経路)。

Create new circuit は active が何であっても常に許可する (unlocked My の新しい回路を末尾に追加して active 化し、既存回路を上書きしない)。 Lock toggle は永続状態として扱うが undo history には積まない (履歴は circuit の編集を扱う単位で、メタ状態は別)。

ガード対象は「現在の回路内容を書き換える操作」と「ピッカー内で対象行の名前・存在を変える操作」。 active が unlocked My でも、対象行が locked My / Example なら Rename / Delete は拒否する。 Duplicate / Select / Create new circuit / Move up / Move down / Reorder / Lock toggle は、回路内容を上書きしないため locked でも通す。

§ 06 Tooltip / アクセシビリティ

tooltip は既存ボタンと同じ .on_hover_text() を使い、文字列は英語に統一する (既存 Undo / Redo / Clear circuit / Duplicate circuit に揃える)。

状態tooltip支援技術へ伝える意味
unlocked (my)Lock circuitToggleButton, Toggled::False
locked (my)Unlock circuitToggleButton, Toggled::True
locked (example)Locked (sample) — duplicate to editToggleButton, Toggled::True + Disabled

注意: § 01 のモックでは aria-pressed / aria-disabled 属性を直接付けている。 本番 UI でも支援技術に ToggleButton / Toggled / Disabled 相当の意味が伝わることを受け入れ条件にする。 モック上の aria は HTML レビュー用の補助表記として扱う。

§ 07 導入要件

ロック状態と編集制御

  • Example は常に locked。My はユーザーが lock ボタンで切り替える。
  • locked 中はゲート配置 / 移動 / 削除、Clear、Undo / Redo、実行中の URL 適用、Rename、Delete を抑止する。
  • Duplicate は常に許可し、新しい My 回路として unlocked で作る。ロック状態は継承しない。
  • Create new circuit は active が何であっても許可し、unlocked My を作成して active にする。
  • Move up / Move down / Reorder は My 内の順序だけを変えるため、locked My でも許可する。Example の順序は固定。

ピッカーのセクション

  • Example Circuits と My Circuits を分けて表示する。
  • Example 行は drag 並び替え・Rename・Delete を受け付けない。
  • My 行は My セクション内だけで並び替えでき、Example セクションへ跨がない。
  • locked My 行は Rename / Delete を無効表示にし、Duplicate / Move up / Move down は維持する。

受け入れ条件

  • unlocked My / locked My / locked Example の 3 状態が § 03 と同じ見た目になる。
  • locked 中の編集操作で回路内容が変わらない。
  • Duplicate は Sample / locked My / unlocked My のどれからでも unlocked My を作る。
  • URL からの回路読み込みは locked My を上書きしない。
  • ピッカーの Example / My セクション境界を越える drag 並び替えは起きない。
