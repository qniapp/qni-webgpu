制御ゲート (|1⟩ 条件)

Control は、同じ列の対象ゲートを |1⟩ 条件にする制御マーカ。 回路上では 40 × 40 px の透明な領域の中央に cyan-400 の塗りつぶし円を描く。 対象ゲートと同じ列に並ぶと、中心同士を 4 px 幅の縦コネクタで結び、 CNOT / CZ / 多重制御ゲートのような多量子ビット操作として読む。

§ 01概要 (見た目と用途)

制御ゲート自体は状態ベクトルを直接変えない。列内の対象ゲートに |1⟩ 条件を付ける 「修飾子」として働く。たとえば Control と X を同じ列に置くと CNOT、 Control と Z を同じ列に置くと CZ になる。

単体マーカ
|1⟩ 条件
CNOT
制御 + X
ホバー
stroke-only の紫枠

縦コネクタは「この列に制御条件がある」ことを示す補助線。対象ゲートの本体を塗り替えず、 同じ列にある制御マーカと対象の中心だけを接続する。

§ 05列内の接続と意味論

制御条件は列単位で集計する。Control は control_mask と control_value の両方へ制御ビットを立てる。 対象ゲートは、その制御ビットが 1 の基底成分にだけ作用する。

Control + X
CNOT
単独配置
対象ゲートがない単独の制御マーカは操作なし。視覚上の縦コネクタも出さない。
複数制御
同じ列に複数の制御マーカを置くと、対象ゲートは多重制御になる。
制御だけの列
塗りつぶし制御が 2 個以上で対象がない列は、CZ / CCZ 系として扱う。
Swap との関係
Swap の縦線は専用コネクタで描く。制御付き Swap の条件は同じ列の制御条件を使う。
