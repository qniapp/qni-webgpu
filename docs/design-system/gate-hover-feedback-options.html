ホバー枠の四角フィードバック案

現状の薄いグレー枠は Flexoki の ui-2 近辺で、背景 bg-2 と近すぎるため認知しづらい。 ここでは「ゲート本体の色や意味論を壊さない」「Probability / Measurement の GPU readout を覆わない」ことを条件に、四角いホバー表現を比較する。

1. 内容の上に描かない Probability bar / 測定桁 / ブロッホ矢印は GPU overlay の情報。hover は本体外側、または本体背面へ。
2. 青系を主アクセント Flexoki Light の blue-600 を使い、既存の step-preview や state panel と関係づける。
3. 32px ゲートで判別可能 2px stroke + 4px outer halo 以上。1px の ui-2 枠だけにはしない。

比較と推奨

案 視認性 情報を覆わないか 実装メモ
案 A high — 32px でも明確 外側の枠なので安全 hover_frame_border / hover_frame_halo role を追加し、既存 hover rect を置換。
案 B very high — 最も強い 背面 pad なので安全 tooltip と重なると紙面が増える。パレット hover にはよい。

案 D high — 列選択と連動 外側の枠 + rail なので安全 回路上限定ならよい。パレットでは rail の意味が薄い。
案 E high — 色差が大きい 外側の枠なので安全 keyboard focus と共用しやすいが、drag 色と意味が近い。
