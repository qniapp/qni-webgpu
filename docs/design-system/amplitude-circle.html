振幅円

複素値 z = re + i·im を、セル内の 輪郭円 + 振幅円盤 + 円盤境界線 + 位相針で表す横断プリミティブ。 円盤の半径は大きさ |z|、位相針の向きは偏角 arg(z) に対応する。 振幅表示ブロック、密度行列表示ブロック、状態ベクトルパネルが同じ語彙で複素量を描けるように、セルの内側だけを本仕様に集約する。

§ 01 見た目と用途

振幅円は「セル 1 個の中に描かれる複素量」の視覚部品。外側の行列枠、セル間隔、ホバー枠、ラベル、ポップアップは使用側の責務にする。 下の例では、位相 0 度を真上、+90 度を左、-90 度を右として描く。 円盤半径は入力した mag、円盤面積は mag² に比例する。

密度行列表示ブロックでは、対角成分は実数の確率値なので needle="false"、非対角成分は複素値なので位相針ありで使う。 振幅表示ブロックと状態ベクトルパネルでは、各セルに位相針ありの振幅円を使う。

§ 02 レイヤ構成

輪郭円セル内の単位円。非ゼロ値は tx-2、ゼロ値は ui-2。大きさを読む基準線。
振幅円盤|z| に比例して半径が変わる青い円盤。面積は |z|² に対応する。
円盤境界線円盤の外端を blue-400 の 1 px 線で締める。小さい円盤では潰れるため省略可。
位相針中心から単位円の端へ向かう線。arg(z) を示す。確率だけを描く場合は使用側が省略する。

§ 04 ジオメトリと式

入力値z = re + i·im。大きさ mag = clamp(sqrt(re² + im²), 0, 1)、位相 phase = atan2(im, re)。数式内の phase はラジアン、文書用 Web Component の phase 属性は度数法。
半径基準outline_radius = cellPx / 2 - stroke / 2 - 1.5、inner_radius = outline_radius - stroke / 2。
円盤半径disk_radius = mag × inner_radius。円盤は輪郭円の内側に収め、外側の行列枠やホバー枠に触れさせない。
位相方向位相 0 を真上に置く。方向ベクトルは (-sin(phase), -cos(phase))。
線幅cellPx ≥ 24 では 2 px、それ未満では 1 px。Tailwind 4 px 倍数のセル寸法内で潰れにくくする。
小セルcellPx < 12 では位相針を省略し、cellPx < 3 では使用側がヒートマップへ切り替える。

§ 05 使用側の差分

使用側振幅円の使い方使用側の責務
振幅表示ブロック全セルに mag + phase を描く。確率を面積として読ませるため mag = sqrt(p) を渡し、位相針を表示する。グリッド寸法、行列外枠、リサイズハンドル、セルポップアップ、span 上限。
密度行列表示ブロック対角成分は行列値としての確率 p = ρᵢᵢ を半径で比較し、位相針を省略。非対角成分は ρᵢⱼ の大きさと位相を描く。正方行列、対角 / 非対角の意味付け、混合状態の説明、span 上限。対角セルは面積ではなく半径で値を読む例外。
状態ベクトルパネル状態ベクトルの各成分を同じ半径・位相規約で描く。拡大縮小、パン、アスペクト比。
ポップアップ内の小見本必要なら小サイズの振幅円を補助図として使う。数値整形、基底ラベル、位置決め、背後 UI への入力遮断。

どの使用側でも、本番 UI 経路では CPU への読み戻しを発生させない。振幅円は「どう描くか」の語彙であり、値の取得方法を増やす理由にはしない。

§ 06 描画メモ

  • 輪郭円、円盤、位相針を 1 つの視覚単位として合成し、拡大時も線幅と位相の読み取りを保つ。
  • 本仕様ページのモックは基準となる見た目の確認に使う。
  • セル背景、行列外枠、ホバー枠、選択枠、リサイズハンドルは振幅円に含めない。重ね順の衝突を避けるため、親コンポーネントが外側のレイヤを管理する。
  • 「振幅円」という名前は、物理量が振幅とは限らない密度行列の非対角成分にも使う。ここでは「複素値を円で表す描画語彙」という意味。
