X ゲート (Pauli-X / NOT)

単一量子ビットを |0⟩ ↔ |1⟩ に反転させる Pauli-X ゲート (古典的な NOT に対応)。 回路エディタ上では 40 × 40 px の塗りつぶし円に Plus (⊕) グリフを中央配置した、 H / Y / Z とは異なる円形の見た目で描画する。これは CNOT のターゲット記号と同じ Plus を 用いることで、「Plus = ビット反転」という視覚規約を回路全体で統一する Quirk 由来の方針。

§ 01概要 (見た目と用途)

Pauli-X は古典 NOT に対応する基本 1 量子ビットゲートで、Quirk / Qni では Hadamard とともに もっとも使用頻度が高い。デザイン上の特徴は H / Y / Z と本体形状が違うこと。Y / Z は H と同じ 「cyan-400 の角丸正方形 + 文字グリフ」だが、X だけは cyan-400 の塗りつぶし円 + Plus グリフ になっている。これは X = NOT を表す ⊕ 記号 (CNOT のターゲットと同じ) を踏襲しているため。

§ 04グリフ (Plus / ⊕)

X ゲートの中央に描かれるのは文字 "X" ではなく、太い Plus 記号。これは古典 NOT の ⊕ 表記、 および CNOT のターゲット記号 (制御線で結ばれた ⊕) と完全に同じグリフを使うことで「Plus = ビット反転」という 視覚規約を統一する狙い。

H ゲートの文字 "H" は本体高の約 55 % だが、Plus は約 30 % にとどまる。これは文字グリフが上下に bearing (アセンダ / ディセンダ) を含むのに対し、Plus は外形いっぱいまで塗りが伸びるため、視覚的にはほぼ同じ占有感に 落ち着くから。腕の太さ (本体直径の約 6 %) も Geist 700 のステム幅と近い。

CNOT ターゲットと同じグリフ

Pauli-X の Plus グリフは、制御線 (control connector) と組み合わさったときの CNOT ターゲット記号 ⊕ と 完全に同じパス。下図のように並べると、本体色 / グリフ / 寸法がすべて一致し、唯一の違いは 「制御線 + 制御ドットが上から伸びているか否か」だけ。

§ 06回路グリッド上の配置

X ゲートは 1 量子ビットゲートなので、1 本の量子ビットワイヤ上の単一スロットに置かれる。スロットは 56 × 56 px 等間隔で並び、本体 40 px 直径は各スロットの中央に来る (上下左右に 8 px の余白)。 これは H / Y / Z など他の 1 量子ビット操作ゲートと完全に共通。形状が円であっても占有スロットは正方形であることに注意。

上のモックは 56 × 5 = 280 px の量子ビットワイヤ (ui-2 1 px) に、3 個の X を 1 スロットおきに並べたもの。うっすら入っているスロット境界の ui 線は説明用で、 実 UI には描画されない。本体が円なのでワイヤ (灰色の水平線) が円の左右両端に当たって自然に隠れる (角丸正方形より柔らかい接続に見える)。

隣接ゲートとの余白

ピッチ 56 px に対し本体 40 px なので、隣接スロットに置かれたゲートとの間には 16 px の余白 が常に確保される。これは ホバー枠 (本体外側 4 px) + 背景の空き (2 px) + 反対側の枠 (4 px) + 反対側の背景の空き (2 px) を合計 12 px、さらに視覚的な余白 4 px を含む値。連続するゲートでも 枠が重ならない よう余裕を持って設計されている。本体形状が円か正方形かに関わらず、同じ余白計算が成り立つ。

§ 07設計判断

他の 1 量子ビットゲートと共通の判断 (本体色 cyan-400 / stroke なし / paper グリフ / span = 1 固定) は h-gate.html § 07 を参照。ここでは X 固有の判断だけを挙げる。

  • X だけ円形にする理由: Pauli-X は古典 NOT に対応し、量子回路の慣習では ⊕ (Plus in circle) で描かれてきた。CNOT のターゲットも同じ ⊕ なので、単独 X と CNOT ターゲットで同じ見た目を共有することで「Plus = ビット反転」という視覚規約を統一できる。形状で X を識別させることで、Y / Z (文字グリフ) と一目で区別できる利点もある
  • Plus グリフは文字ではなくベクタパス: 文字 "+" を font で描くと、Geist の "+" は記号バランスが細く、CNOT の太い ⊕ と一致しない。gate-palette.html canonical の g-X シンボル (Plus パス) を 1:1 で使うことで、SDF テクスチャ焼き込みとも整合性をとる
  • ホバー枠は同心円: 本体が真円なので、枠も border-radius: 50% で同心円にする。これは H ゲートの角丸枠と形状だけ違って論理は同じ: 本体外側 4 px の purple-400 + 2 px 背景の空き という幾何関係は完全に共通
