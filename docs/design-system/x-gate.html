X ゲート (Pauli-X / NOT)

1 量子ビットの NOT ゲート。|0⟩ と |1⟩ を入れ替え、CNOT のターゲットにもなる。 共通クロムは gate-chrome.html を正とし、本ページでは X 固有の意味論、 components/x-gate.js の Shadow DOM、X としての設計判断だけを定義する。

§ 00本ページの責務

共通クロムは ゲートクロム共通仕様 を正とする。 本ページは X ゲート (Pauli-X / NOT) としての意味、字形、固有の設計判断を定義し、真円の塗りつぶしゲートとして扱う。ただしホバー枠は真円にせず、共通クロムの角丸枠を継承する。外装・配色・状態表現・配置方針はリンク先を参照する。

gate-chrome.html が正ゲート本体の外装、配色ロール、状態表現、回路グリッド上の配置方針。
x-gate.html が正Pauli-X / NOT の意味、Plus グリフ、真円本体を採用する判断。ホバー枠は共通クロムを継承する。
個別ページで再定義しない本ページでは共通クロムの値を再定義しない。共通値の変更が必要な場合は、ゲートクロム共通仕様を更新する。

§ 01概要 (見た目と用途)

X ゲートは計算基底を反転する基本ゲートで、Quirk / Qni では CNOT ターゲットと同じ plus-in-circle の慣例を使う。H ゲートと同じ共通クロムを継承しつつ、形状だけは「反転 / ターゲット」を示す真円として扱う。

§ 04回路グリッド上の配置

X は 1 量子ビットゲートなので、1 本の量子ビットワイヤ上の単一スロットに置かれる。CNOT では制御マーカと組み合わせ、同じ Plus グリフをターゲットとして使う。 スロット寸法、隣接余白、ワイヤとの層関係は gate-chrome.html § 05 を継承する。

点線代わりの薄いスロット境界は説明用で、実 UI には描画しない。X 固有の配置差分だけを本ページで扱う。

§ 05設計判断

設計判断は「共通クロムからの継承」「X 固有」「妥協と将来対応」に分ける。これにより、X だけで変えてよい判断と、ゲートクロム全体を巻き込む判断を混ぜない。

共通クロムからの継承配色ロール、角丸ホバー枠、状態表現、回路グリッド上の配置方針は共通仕様を継承する。
X 固有計算基底の反転と CNOT ターゲットを同じ Plus グリフで表し、本体だけを真円にして角丸正方形ゲートと区別する。
妥協と将来対応Plus グリフの太さや真円本体を変える場合は、CNOT ターゲットとしての読み取りやすさも同時に確認する。
