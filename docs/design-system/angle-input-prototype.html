Design system / Angle input prototype

角度入力 UI プロトタイプ

ワイヤ間隔を変えずに、角度文字列へ下線を出して編集できることを示す案。表示ブロックが同じ回路内にあっても破綻しないことを確認する。

01. インライン案

特徴

  • 角度ラベルは 12px の等幅フォント、Flexoki tx で表示する。
  • クリック後 680ms、またはホバー開始から 680ms は何も表示せず、その後 120ms で角度文字列の下線を一段薄い黒へフェードインする。
  • 上側ラベルは対象ゲートの上端、下側ラベルは対象ゲートの下端 + 2px を基準にする。接続方向が top && bottom のときだけ背景ふちどりを使う。
  • ワイヤ間隔は固定なので、振幅表示ブロックなどを押し広げない。
  • 入力欄はゲート列幅を変えないため、ゲートは下にずれない。

02. 不正入力の扱い

この節では、アプリ実装へ次に反映する不正入力時のふるまいを先に定義する。

A. 入力中

Phase angle

Enter または外側クリックで確定を試みる。入力中は警告を出さず、通常の編集欄のままにする。

B. 確定後

角度ラベル

不正な値は保存せず、編集前の角度に戻す。エラーバッジは出さない。

03. 回路名変更 UI との共存

衝突しないための方針

  • ワイヤ間隔は変更しない。表示ブロックや複数ワイヤゲートの高さを壊さないため。
  • 角度文字列の場所を、下線付きの等幅テキスト欄へ置き換える。
  • 同時に開ける編集 UI は 1 つだけにし、角度入力を開くと回路名メニューを閉じる。
  • 確定は Enter、取り消しは Esc、フォーカス外クリックは妥当な値なら確定、無効値なら編集前の角度へ戻す。

04. 入力規則

  • 1/2 は π/2 と表示する。1 は π、0 は 0 と表示する。
  • 2/4、-2/-4 のように約分できる分数は 1/2 に正規化して保存する。
  • -1/2 は −π/2 と表示し、マイナス記号は表示側で統一する。
  • abc、1//2、分母が 0 の値は保存せず、編集前の角度へ戻す。
  • 小数を許可する場合は 0.25π として表示するが、初期実装は整数と分数だけに絞る案を推奨する。
