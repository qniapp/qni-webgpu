配色

qni-webgpu は Flexoki Light (Steph Ango / kepano) のパレットだけを使う。Tailwind 等の独自色 (sky-500 / zinc-600 / emerald-500 など) は 使わず、必ず Flexoki の名前付きトーンにマップする。実装側の名→トーン対応は apps/web/src/colors.rs の flexoki_light() が単一の出典。

§ 01中性色 (Neutrals)

背景 / 枠線 / テキストの 3 役を担うグレースケール 7 段階。Flexoki base 系の派生で、 背景は paper (bg) と base-50 (bg-2) の 2 段だけ、それ以外は枠 / テキストに割り当てる。

--ui #E6E4D9 · base-100

--ui-2 #DAD8CE · base-150

量子ビットワイヤ / グリッド / ゲート外周 / 行区切り

§ 02アクセント色 (Accents)

用途別の色相群。Blue は状態 / 振幅 / ステップ、Purple はインタラクション (hover / drag)、Red / Green は意味論 (|0⟩ / |1⟩ / completed / failed) に紐づく。 Yellow / Cyan / Orange は補助ドキュメント (サンプル回路選択ページなど) で使う。
