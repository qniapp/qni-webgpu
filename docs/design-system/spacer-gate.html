Spacer ゲート (空きスロット)

回路上に何も作用しない空きスロットを明示的に置くためのプレースホルダ。 見た目は 40 × 40 px の透明な当たり判定領域 + tx の 3 点だけで、 cyan-400 の角丸本体も、行列変換も、測定も持たない。列の間隔や例題回路の読みやすさを保つための視覚的な区切りとして扱う。

§ 01概要 (見た目と用途)

Spacer のシリアライズ ID は "…" (三点リーダー 1 文字)。 パレットでは Gates section の 2 行目末尾に置かれ、ドラッグするとほかのゲートと同じ 56 px ピッチのスロットへ配置できる。 ただし、状態ベクトルには一切作用しないため、回路の意味論としては「列を占有する空白」に近い。

回路ホバー
purple-400 の線

Spacer の役割は「見える空白」。通常の空セルは何も描かれず選択もできないが、Spacer は 3 点で存在を示し、ドラッグ / ホバー / 削除などの編集操作を受け付ける。

§ 04状態バリアント

Spacer は本体色を持たないため、状態差はホバー枠とカーソルだけで伝える。 ドラッグ中も 3 点の色は変えず、「仮配置中」の紫色本体を出さない。

① 既定
tx の 3 点
② 回路ホバー
2 px stroke
③ パレットホバー
内側の空き
④ ドラッグ
色変化なし

パレット上だけ内側を paper で塗る。回路上で同じ処理をすると、透明ゲートの内部を通る wire や制御線を消してしまうため、回路上は線だけのホバー枠に統一する。

§ 05回路グリッド上の配置

Spacer は 1 本の量子ビットワイヤ上の単一スロットを占有する。空セルとは違い、3 点が表示されるため、列幅の確保や例題回路の視線誘導に使える。

うっすら入っている縦線は説明用のスロット境界。実 UI では wire と 3 点だけが見える。単独の Spacer はコネクタを作らず、span も伸びない。同じ列に Control / Anti-control がある場合は描画上の対象として縦コネクタに含まれるが、状態変化はない。

§ 06意味論と導入要件

状態変化
Spacer は状態ベクトルに作用せず、計算ステップを発生させない。
編集操作
配置・選択・削除・ドラッグは通常ゲートと同じ。空セルではなく、編集可能なプレースホルダとして扱う。
外部 GPU 実行
未対応の経路では Unsupported gate · Spacer として停止する。
  • 3 点だけで描く: 空白を示す記号なので、操作ゲートの cyan-400 本体や枠線を足さない。
  • tx を使う: tx-2 では wire 上で弱すぎ、tx なら小さな 5 px 点でも見失わない。
  • wire マスクをしない: Spacer は回路の流れを止めない。wire が連続していることを保ち、点だけが上に乗る。
  • ドラッグ中に紫化しない: 本体 fill が無いゲートに purple-600 の仮本体を出すと、Spacer が操作ゲートに見えるため避ける。
  • span = 1 固定: 列を占有するだけで、複数量子ビットの領域を持たない。リサイズハンドルは出さない。
