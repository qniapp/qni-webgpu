Ry ゲート (Y 軸回転 θ)

単一量子ビットへ e−iθY/2 を適用する Y 軸まわりのパラメタ可変回転ゲート。 回路エディタ上では 40 × 40 px の cyan-400 角丸正方形に Geist Bold 由来の 2 文字グリフ "Ry" を中央配置する。 回転角 θ は配置後にパラメタ編集ポップオーバで決め、見た目では H / Y / Z / S / T / Rx と同じ 1 量子ビットゲートの chrome を継承する。

§ 01概要 (見た目と用途)

Ry は Y = Pauli-Y の連続版で、任意角 θ の ブロッホ球 Y 軸まわりの回転を表す。 θ = π で Ry(π) = −iY となり大域位相を除いて Y と一致する。 Y 軸回転は行列要素がすべて実数になるため、実係数だけで |0⟩ と |1⟩ の振幅を連続に 混ぜたい場面 (ansatz の variational layer / 状態準備など) で多用される。 見た目では「固定角」「任意角」を別色にせず、cyan-400 = ユニタリ操作ゲートという既存の色対応を守る。 Ry 固有情報は字形 "Ry" と説明文、そしてパラメタ編集ポップオーバの θ 値に閉じる。

§ 04字形 (Ry)

中央字形は gate-palette.html の基準 SVG g-Ry と同じ path / transform を使う。 CSS のテキスト描画ではなく、palette 側で定義された "R" + "y" の 2 つのベクタ字形を 40 px 本体へ重ねる。 H / Y / Z / S / T が単一文字なのに対し、Ry は 大文字 R + 軸ラベル y の 2 字形でひと組。 文字としては「Ry」(大文字 R + 小文字 y) の学術記法を採るが、Geist Bold の path はベースライン以下に descender を持たない uppercase Y 形状を縮小して配置している (g-Y の path と y 座標 0〜710 がほぼ一致)。 Rx / Rz / 大文字 R 始まりのパラメタ可変ゲートと字形パターンを共有する。

§ 06回路グリッド上の配置と θ パラメタ編集

Ry ゲートは 1 本の量子ビットワイヤ上の単一スロットに置く。スロットは 56 × 56 px 等間隔、 本体 40 px は中央配置で上下左右に 8 px の余白を持つ。配置後にクリックすると θ 値編集ポップオーバが開く。

うっすら入っているスロット境界の ui 線は説明用で、実 UI には描画されない。 隣接スロットへ連続配置しても、本体間には 16 px の余白が残り、ホバー枠同士が重ならない。

θ パラメタ編集ポップオーバ (モック)

Ry は配置後に回転角 θ を編集する。ポップオーバは cell の右下から 8 px のオフセットで開き、 自由入力 (ラジアン / 数式) と π 系プリセット (0 / π/4 / π/2 / π / 3π/2) の併用を許す。 値編集中もゲート本体の色 / サイズは変えず、現在の θ はセル下に数値ラベル (例: π/2) として描く。

ポップオーバ自体の chrome (枠 / 影 / 角丸) はトーストや context menu と共通の primitive にそろえる予定 (別仕様で定義)。Rx / Rz / P も同じポップオーバを共有し、ラベル ("RX" / "RY" / "RZ" / "PHASE") とプリセット集合のみが差分。

§ 07意味論と設計判断

行列
Ry(θ) = [[cos(θ/2), −sin(θ/2)], [sin(θ/2), cos(θ/2)]]
要素はすべて実数 (Rx / Rz と違い i を含まない)
基底状態
Ry(θ)|0⟩ = cos(θ/2)|0⟩ + sin(θ/2)|1⟩
Ry(θ)|1⟩ = −sin(θ/2)|0⟩ + cos(θ/2)|1⟩
ブロッホ球
Y 軸まわりの θ 回転。θ = π で確率を完全反転 (= Y, 大域位相を除く)。 θ = π/2 は |0⟩ → (|0⟩+|1⟩)/√2 で H と似た方向に動かすが、|1⟩ の符号が違い大域位相を含めても H とは等価でない。
関係
Ry(0) = I / Ry(π) = −iY / Ry(2π) = −I / H = X · Ry(π/2)
  • H / Y / Z と同じ角丸正方形にする: Ry は文字グリフで識別する通常の 1 量子ビットゲート。X だけは CNOT ターゲットと同じ ⊕ 記号を共有するため円形にする
  • 2 文字グリフ "Ry" を採用する: 大文字 R で「Rotation」、小文字 y で「軸ラベル」を表す。これは Qiskit / Cirq / Quirk と一致するアカデミック表記。すべて大文字 "RY" は palette の他のゲート (H / Y / Z / S / T) と並べたとき視覚的に重く、字形バランスが崩れる
  • "Ry" の "y" は descender を持たない: 学術記法では小文字 y を使うが、Geist Bold の path (M243 0V285L-6 710H...) は y=0 (ベースライン) より下に伸びる descender を持たず、uppercase Y 形状を縮小した姿で 40 px box に収まる。これにより H / Y / Z / S / T と同じ視覚高さで揃う
  • x オフセット 23.923 は Geist Bold 由来: Rx (23.724) / Rz (24.673) と微妙に違うが、これは Geist Bold が R + 各字形のペアごとに letterspacing を持つためで、視覚的中心を揃えるために palette の値をそのまま使う
  • 回転角 θ を色で表現しない: θ は連続パラメタなので色相 / 明度マッピングは不安定 (θ = π と θ = π + 0.001 が同色)。θ の現在値はセル下の数値ラベルとポップオーバ (§ 06) に閉じる
  • Ry(π) と Y を別カードとして残す: 数学的には大域位相を除いて等価だが、ハードウェア / 教育文脈では「Y = 固定回転 π」「Ry = 連続パラメタ」と役割が違うため、palette でも UI でも別ゲートとして並べる
  • Ry(π/2) と H を「等価」と書かない: Ry(π/2) は (|0⟩+|1⟩)/√2 を作るが、|1⟩ 側で符号が反転するため大域位相を除いても H と一致しない (H = X · Ry(π/2))。ansatz 文献の "Ry-only ansatz" 等を読むときに H とは別物として扱う
  • stroke を持たない: 本体色 cyan-400 が wire (ui-2) や背景 (bg-2) と十分区別できるため、枠線は足さない
  • span = 1 固定: Ry は単一量子ビットだけに作用するため、表示ブロックや QFT のような span リサイズを持たない

§ 08関連仕様

ドキュメント関係
H ゲート (Hadamard) 角丸正方形 + 文字グリフの基本仕様。Ry は同じ chrome を 2 文字グリフ版で継承する。H = X · Ry(π/2) で大域位相を含めても等価ではない
Y ゲート (Pauli-Y) Ry(π) と大域位相を除いて等価。固定回転 π としての Y と連続回転の Ry の使い分けを定義する
Rx ゲート (X 軸回転 θ) 同パターンの X 軸版。字形 ("Rx" / "Ry")・kerning・行列の i の有無のみが差分
X ゲート (Pauli-X / NOT) Y 軸ではなく X 軸の固定回転 (π)。H = X · Ry(π/2) の右因子として登場し、Ry と組み合わせて H を作る話で参照する
Z ゲート (Pauli-Z) Z 軸の固定回転 (π)。Y / Ry に対する Z / Rz の対応関係で並べる
T ゲート (位相 π/4) Z 軸の固定 π/4 回転。Ry(π/4) (Y 軸の同角度) と並べると、軸違いでどう動くかが対比できる
Gate palette パレット上の Ry ゲート (ドラッグ元) の基準 SVG g-Ry を定義する。Rx / Rz も g-Rx / g-Rz として隣接配置
ホバー枠 purple-400 + 背景の空き のホバー枠 primitive。Ry は角丸正方形版を使う
配色 box_fill = cyan-400、gate_hover_border = purple-400、drag_fill = purple-600 などのロール → トーン対応
gate-size-40px-migration ゲートサイズを 40 px に統一した経緯 (本仕様の前提)
