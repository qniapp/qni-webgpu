振幅円ポップオーバー

振幅円をホバーしたときに表示する詳細情報カードの仕様。 状態ベクトルパネルと振幅表示ブロックの振幅円は同じ視覚部品なので、ポップオーバーの内容、数値形式、三角形の近さも同じにする。

§ 01 適用範囲

対象状態ベクトルパネルの振幅円、振幅表示ブロックの各セル。どちらも同じ |bin(k)⟩ decimal k 見出しと 3 行値一覧を使う。
外装ポップオーバー共通仕様の面、枠、角丸、影、tail を使う。ここでは振幅円に結び付ける配置と内容だけを定義する。
非対象確率表示ブロックの行詳細、密度行列表示ブロックのセル詳細、ブロッホ球表示ブロックのベクトル詳細。これらはそれぞれ独立したポップオーバー仕様を持つ。

§ 02 内容と数値形式

見出しはホバー中の測定結果を最も強く示す。値は状態ベクトルパネルと同じ Amplitude: / Probability: / Phase: の 3 行に固定する。 VAL / MAG² / PHASE の省略ラベルや、raw / log だけの 2 行カードへは切り替えない。

見出し|bin(k)⟩ decimal k。Geist Mono text-sm (14 px / 20 px)。
Amplitude:+0.70711+0.00000i。実部と虚部を小数点以下 5 桁で表示し、符号を必ず付ける。
Probability:+50.0000%。|amp|² × 100 を小数点以下 4 桁で表示し、符号を必ず付ける。
Phase:+0.00°。度数法で小数点以下 2 桁表示し、符号を必ず付ける。
非コヒーレント状態行数と高さは変えない。振幅と位相は未定義なので —、確率だけを Probability: 行に表示する。

§ 03 配置

第 1 候補は対象の振幅円の上。ポップオーバー本体を円の中心に揃え、tail (三角形) の先端を輪郭円から 4 px (spacing-1) だけ離す。 上に置けない場合だけ下へ反転する。左右に離して置く配置は採用しない。

|1⟩ decimal 1
Amplitude:+0.70711+0.00000i
Probability:+50.0000%
Phase:+0.00°
anchor gaptail (三角形) の先端と輪郭円の距離は 4 px。セル矩形ではなく、振幅円の輪郭円を基準にする。
水平位置通常は振幅円中心に本体中央を揃える。画面端で本体を寄せる場合も、tail は可能な限り円中心へ向ける。
反転上側に十分な空きが無い場合だけ、top tail で対象の下へ置く。左右配置は、確率表示ブロックの細い行のような対象に限定する。

§ 04 実装メモ

  • 本番 UI 経路では GPU 上の状態値を CPU へ読み戻さない。値欄は glyph atlas と overlay shader で GPU storage buffer から直接描画する。
  • 固定ラベル、アイコン、外装は CPU 側のレイアウト情報として持ってよい。振幅値、確率値、位相値そのものを CPU へ渡して文字列化しない。
  • 振幅表示ブロック側の動く仕様モックは components/amplitude-display.js にあり、本ページの内容・配置へ合わせる。
