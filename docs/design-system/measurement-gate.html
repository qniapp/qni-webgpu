測定ゲート (Measurement)

量子ビットを Z 基底で射影測定し、結果に応じて状態ベクトルを収縮させる非ユニタリ操作。 見た目は cyan-400 のゲート本体を持たない 透明な 40 × 40 px 領域 + purple-600 のメーター。 測定後はメーターを wire と同じ ui-2 に落とし、GPU が直接描く red-600 の 0 / blue-600 の 1 だけを重ねる。

§ 01概要 (見た目と用途)

測定ゲートは、回路の途中で量子ビットを古典ビットへ読み出す操作。URL 用トークンは "Measure"。 H / X / Rz のような可逆な回転ではなく、 サンプル結果 0 または 1 を選び、その基底へ状態を射影して後続列へ渡す。

§ 04状態バリアント

測定ゲートは、本体色をドラッグ中に変えない。透明領域 + メーターという形を保ち、意味色は「未測定 purple」「測定後 red / blue」に限定する。

パレットのホバーは外側 purple-400 + 内側 paper の二重枠、回路上のホバーは本体外側 4 px に置く 2 px の線だけ。 回路上で内側を塗るとコネクタや wire を消すため、透明ゲートでは線だけに統一する。

§ 05回路グリッド上の配置

スロット中心に 40 px のメーターを置き、wire はゲート直下だけ背景で短く切る。結果ディジットは測定後に同じ位置へ重ねる。

うっすら入っている縦線は説明用のスロット境界。実 UI では wire とゲートだけが見える。 測定後もゲート位置は変えず、結果だけを重ねるため、後続列との読み順が安定する。

§ 06意味論と導入要件

計算
列ごとに pZero を GPU で求め、決定論的乱数で 0 / 1 をサンプルする。
収縮
選ばれた基底へ状態を射影し、√p で再正規化して後続列へ渡す。
描画
本番 UI 経路で CPU 読み戻ししない。結果ディジットも同じ GPU 表示経路で重ねる。
  • 角丸本体を持たない: 回転ゲートではなく読み取り操作なので、cyan-400 の塗りつぶしゲートと視覚的に分ける。
  • 未測定色は purple-600: 0 / 1 のどちらにも属さない中間状態として扱い、結果の赤 / 青と衝突させない。
  • 測定後メーターを中性化する: 読み取るべき情報はディジットなので、メーターは wire と同じ ui-2 へ退かせる。
  • wire を短く切る: メーターの内部を横線が通ると針と競合するため、左右 4 px だけ広く背景でマスクする。
  • span = 1 固定: 1 つの測定ゲートは 1 量子ビットだけを測定する。複数量子ビット測定は各 wire に 1 個ずつ置く。
