デザインシステム / 周辺 UI / ゲートパレット

qni-webgpu · design system · widget spec

Gate palette

回路エディタ上部中央に常駐する 2 行のゲートパレット。各セル 40 × 40 px のアイコンを配置元として、回路グリッドへドラッグして配置する。 操作ゲート領域 / 表示ブロック領域 / 垂直ディバイダの 3 領域に分け、見た目上のスロット順序を明確にする。

§ 01 動くモック

仕様上の寸法 (40 × 40 アイコン / 8 px gap / 16 × 20 padding / 12 px 角丸 / paper 背景 + 25 % 透明度の影) と 各ゲートのアイコン形状を再現。 パレットは 操作ゲート領域 (左) + 2 px ui-2 垂直ディバイダ (2 行高) + 表示ブロック領域 (右 2 × 2) に分割。 アイコンにホバーすると purple-400 外枠 (外側 4 px / 角丸 10 px) + paper 内枠 (外側 2 px / 角丸 8 px) の枠が出る。 表示ブロック領域は 2 × 2 の 4 スロットすべてを使う。

§ 03 パレット要素一覧

§ 05 ホバー / ツールチップ

ホバー枠

  • 外枠: アイコン領域の外側 4 px まで広げ、角丸 10 px、色は purple-400
  • 内枠: アイコン領域の外側 2 px まで広げ、角丸 8 px、色は paper
  • 差分 = 2 px の purple-400 枠が要素周囲に出る。内側を paper で塗り直すのは Measurement / Spacer のような本体 fill を持たないゲートでも背景が灰色 (palette bg) に変わらないため
  • その上に本体とアイコンを重ねる
  • Spacer 含む全 26 要素に対して同じホバー枠を出す

ツールチップ

  • 表示条件: ホバー中 かつドラッグ未開始 (ドラッグ開始で即非表示)
  • 位置: アイコン下、12 px 余白
  • 内容: 要素名 (太字) + 説明文 + 一部ゲートは変換図 (行列表記 / ブロッホ球での変換イメージ)
  • 背景: surface + line (ui-2) 1 px border + soft shadow
  • 説明文に加え、必要なゲートでは変換図や振幅表示の補足を出す。

§ 06 ドラッグ挙動

ドラッグ開始

  • パレットアイコンを押したとき、領域単位で当たり判定を行う。
  • 当たったらすぐドラッグを開始し、マウス位置を中心にプレビューを表示する。
  • ドラッグ開始の移動しきい値は無し: 押下と同時にドラッグ開始 (パレット → 回路は新規配置なので閾値不要)
  • Spacer も同じ挙動: ドロップすると回路上で空きスロット (作用なしの placeholder) として配置される

ドラッグ中

  • パレットアイコン自身は残り続ける。同じパレットから何度でもドロップ可能
  • カーソル下にプレビューが浮く。回路グリッド上の他要素とは独立した専用オーバーレイとする。
  • 本体色を持つゲートのプレビュー本体色は purple-600 (通常時の cyan-400 と区別)。Write0 / Write1 / Measurement / Spacer など本体なし系は字形色や本体なしの見た目を維持する
  • カーソルは grabbing

ドロップ

  • ドロップ位置に最も近い回路スロットへ配置する
  • 配置はスナップ / 列挿入 / 衝突検出の規則に従う
  • ドロップ不可な位置 (他要素と衝突 / 範囲外) では何も配置しない
  • ドロップ成功時は回路に新しいゲートまたは表示ブロックを追加し、現在の回路として保存する

§ 08 検討事項

現時点の範囲

  • 2 領域レイアウト: ゲート領域 (2 行 × 22 個) + 2 px ui-2 垂直ディバイダ + 表示ブロック領域 (2 × 2 グリッド、4 個)。
  • 全 26 要素に同じホバー枠とツールチップの外装を適用する。
  • ドラッグは押下で即開始し、Spacer も含めて配置元として扱う。
  • Spacer はゲート領域 2 行目末尾に置き、ドロップすると回路上の空きスロットとして配置する。

今後の検討 / TODO

  • パレット上ゲートの再配置 — ユーザがパレット内のゲート順を入れ替える UI なし。
  • 非表示制御 — 特定の gate を非表示にする設定なし。
  • 複数選択ドラッグ — 複数ゲートを同時にドラッグする UI なし。
  • カスタムゲート — ユーザ定義のゲートをパレットに追加する仕組みなし。
  • 表示ブロック領域の拡張 — 5 つ目以降の表示ブロックを追加する場合は、2 × 2 を超えるレイアウト方針が必要。
  • パラメータ付きゲートの値入力 — Phase / Rx / Ry / Rz は配置後に値を編集する UI が必要だが、パレット側からは設定できない。
