Gate palette

回路エディタ上部中央に常駐する 2 行のゲートパレット。各セル 40 × 40 px のアイコンを drag source として、回路グリッドへゲートを drop して配置する。 実装: apps/web/src/render/circuit_palette/ + src/icons/gate_body.rs + src/icons/gate_glyphs.rs + src/gates.rs (3 配列 PALETTE_GATES_ROW1 / PALETTE_GATES_ROW2 / PALETTE_DISPLAY_GATES に分割) + src/layout/palette.rs (section ベースの hit_test)。

§ 01 動くモック

実コードの寸法 (40 × 40 アイコン / 8 px gap / 16 × 20 padding / 12 px corner radius / paper bg + 25 % alpha shadow) と 各 gate の SVG icon 形状 (gate_body.rs / gate_glyphs.rs) を 1:1 で再現。 palette は Gates section (左) + 2 px ui-2 垂直ディバイダ (2 行高) + Display section (右 2 × 2) に分割。 アイコンに hover すると purple-400 外枠 (4 px 拡張 / corner 10) + paper 内枠 (2 px 拡張 / corner 8) の枠が出る。 Display section は 2 × 2 の 4 スロットすべてを使う。

§ 03 ゲート一覧 (gates.rs)

ゲートは 3 つの配列に分かれて定義: PALETTE_GATES_ROW1: [GateKind; 13]、PALETTE_GATES_ROW2: [GateKind; 9]、PALETTE_DISPLAY_GATES: [GateKind; 4]。 フラットインデックス (0〜25) は section 分割後も安定しており、PALETTE_GATES_ROW2_INDICES = [13, 14, 15, 17, 18, 19, 22, 23, 21] と PALETTE_DISPLAY_INDICES = [16, 20, 24, 25] がそれぞれの slot 順から flat ID へマップする。palette_gate_kind(index) がこのマップを使って GateKind を解決。

§ 05 ホバー / ツールチップ

ホバー枠 (panel.rs:59-69)

  • 外枠 (outer): gate_rect.expand(4.0) · CornerRadius::same(10) · fill = gate_hover_border = purple-400
  • 内枠 (inner): gate_rect.expand(2.0) · CornerRadius::same(8) · fill = surface (paper)
  • 差分 = 2 px の purple-400 枠が gate 周囲に出る。内側を paper で塗り直すのは Measurement / Spacer のような本体 fill を持たないゲートでも背景が灰色 (palette bg) に変わらないため
  • その上に draw_gate_body() が gate body と icon を重ねる
  • Spacer 含む全 26 ゲートに対して同じロジックでホバー枠が出る (palette_hit_test() は Spacer を除外しない)

ツールチップ (tooltip.rs)

  • 表示条件: hover 中 かつ drag 未開始 (drag 開始で即非表示)
  • 位置: gate body の下、12 px 余白
  • 内容: gate 名 (太字) + 説明文 + 一部 gate は変換図 (行列表記 / ブロッホ球での変換イメージ)
  • 背景: surface + line (ui-2) 1 px border + soft shadow
  • サブモジュール: tooltip/layout.rs / tooltip/text.rs / tooltip/amplitude_display.rs / tooltip/diagram.rs

§ 06 ドラッグ挙動

ドラッグ開始

  • パレットアイコンに mousedown したとき、palette_hit_test() (layout/palette.rs) で hit 判定
  • hit したらすぐ DragStartIntent::PaletteGate を発行、新規 PlacedGate を生成 (mouse 位置を中心に preview_pos = mouse_pos − (GATE_SIZE/2, GATE_SIZE/2))
  • drag threshold (移動距離) は無し: mousedown と同時にドラッグ開始 (palette → circuit は新規配置なので閾値不要)
  • Spacer も同じパス: drop すると回路上で空きスロット (作用なしの placeholder) として配置される

ドラッグ中

  • パレットアイコン自身は残り続ける (source は消えない)。同じパレットから何度でも drop 可能
  • カーソル下に preview gate が浮く: render/circuit_palette/drag_preview.rs で専用 overlay 描画 (回路グリッド上の他 gate と z-order が独立)
  • 本体色を持つゲートの preview 本体色は drag_fill = purple-600 (idle の cyan-400 と区別)。Write0 / Write1 / Measurement / Spacer など no-body 系は字形色や本体なしの見た目を維持する
  • cursor は grabbing

drop

  • drop 位置の slot index を計算 (mouse_pos → grid 座標変換)
  • 既存配置 logic と同じ placement: snap / column insertion / 衝突検出
  • drop 不可な位置 (他 gate と衝突 / 範囲外) では snap back (preview が消えて何も配置されない)
  • drop 成功時は placed_gates に新 entry 追加、gpu_plan.mark_dirty()、commit_current_circuit(ctx)

§ 08 実装状況と TODO

完全実装済み

  • 2 section レイアウト: Gates section (2 行 × 22 個) + 2 px ui-2 垂直ディバイダ + Display section (2 × 2 grid、4 個)
  • section ベースの palette_hit_test (gates / display それぞれ別経路 + separator / inter-section gap を除外)、フラット index は 0〜25
  • 各 gate のアイコン描画 (rounded square / circle body / Bloch circle / Probability preview / Amplitude preview / Density matrix preview / no body の 7 タイプ)
  • SDF テクスチャ経由の文字描画 (assets/icons/*.svg → 256 px PNG → SDF)
  • ホバー枠 (purple-400 4 px expand / radius 10 + paper 2 px expand / radius 8) — 全 26 ゲート対応
  • ツールチップ (gate 名 + 説明 + 変換図)
  • drag source (mousedown 即開始、新規 PlacedGate 生成、ドラッグプレビュー overlay) — Spacer 含む全 26 ゲートに対応。purple-600 の本体色は body ありゲートだけに適用する
  • Spacer は Gates section row 2 末尾、drop すると回路上の空きスロットとして配置

未実装 / TODO

  • パレット上ゲートの再配置 (reordering) — ユーザがパレット内のゲート順を入れ替える UI なし
  • 非表示制御 (hide / show) — 特定の gate を非表示にする設定なし (現状は 3 配列で全部表示)
  • multi-select drag — 複数 gate を同時に drag する UI なし
  • カスタム gate — ユーザ定義の gate を palette に追加する仕組みなし
  • Display section の拡張 — 5 つ目以降の表示ブロックを追加する場合は、2 × 2 を超えるレイアウト方針が必要
  • parameterized gate の値入力 — P / Rx / Ry / Rz は placement 後に値を編集する UI が必要だが palette 側からは設定できない
