Phase ゲート (Φ / 位相 θ)

単一量子ビットへ diag(1, eiθ) を適用するパラメトリック位相ゲート。S / T / Z を含む位相系列の汎用形。 共通クロムは gate-chrome.html を正とし、本ページでは位相ゲート固有の意味論、 Qni と同じ Φ ラベル、および既定角 π/2 の角度ラベルに関する設計判断だけを定義する。

§ 00本ページの責務

共通クロムは ゲートクロム共通仕様 を正とする。 本ページは Phase ゲート (Φ / 位相 θ) としての意味、画面ラベル、角度ラベル、真円本体、ラベルと内部表記を分ける判断を定義する。本体形状・配色ロール・線画グリフの具体値は § 03 を正とする。ホバー枠は真円にせず、共通クロムの角丸 10 px 枠を継承する。

個別ページで再定義しない共通クロムの値は再定義しない。共通値の変更が必要な場合は、ゲートクロム共通仕様を更新する。

§ 01概要 (見た目と用途)

Phase ゲートは θ を持つ可変位相ゲートで、固定角の S / T / Z より広い操作を表す。演算は内部表記 P(θ) の行列 diag(1, eiθ) で表す。Rz(θ) = diag(e-iθ/2, eiθ/2) = e-iθ/2 · P(θ) なので、Rz(θ) とはグローバル位相を除いて同じ位相操作を表す。

画面上は真円本体と固定の Φ 字形で「パラメータを持つ位相ゲート」を示す。現在の Φ グリフは θ の値に応じて回転する角度メータではなく、θ の値は本体外側の角度ラベルで表示し、編集は別 UI で扱う。

§ 04回路グリッド上の配置

Phase ゲートは 1 量子ビットゲートなので、1 本の量子ビットワイヤ上の単一スロットに置かれる。角度 θ の編集は本体クロムではなく、別の編集 UI で扱う。ポップオーバーの外装・余白・尾の描画は popover.html を参照する。スロット寸法、隣接余白、ワイヤとの層関係は gate-chrome.html § 05 を継承する。

点線代わりの薄いスロット境界は説明用で、実 UI には描画しない。位相ゲート固有の配置差分だけを本ページで扱う。θ 編集 UI の起動トリガと入力フォームの詳細は、Rx / Ry / Rz / Phase にまたがる共通仕様として別途確定する。

角度ラベル

パレットから回路へドロップした Phase ゲートは既定角 π/2 を持ち、回路上の真円本体の外側に π/2 を表示する。表示文字列は URL トークンから復元した保存済み角度文字列で、例として π/2、1/3π、2π/3 などをそのまま描く。明示的な角度がない旧形式の P も既定角 π/2 として表示し、空文字の角度だけは編集中のプレースホルダーとして角度ラベルを出さない。

角度ラベルは text-xs (12 px) の等幅文字で tx 色を使い、本体から 2 px 外側に置く。単独ゲートや同角ペアの上端では上側、同角ペアの下端では下側に逃がし、同角 Phase 同士を結ぶ縦コネクタと重ならないようにする。3 個以上の同角チェーンでは、中間ゲートのラベルは上側表示に戻す。

§ 05設計判断

設計判断は「共通クロムからの継承」「位相ゲート固有」「ラベルと内部表記」「パラメータ表示方針」に分ける。これにより、位相ゲートだけで変えてよい判断と、ゲートクロム全体を巻き込む判断を混ぜない。

共通クロムからの継承本体色は box_fill、ホバー枠は gate_hover_border、ドラッグ中は drag_fill を使う。Phase だけ色を変えると S / T / Z / Rz との同系性が崩れるため、配色ロールは共有する。
位相ゲート固有本体だけを真円にし、固定の Φ 字形で可変位相ゲートだと示す。ホバー枠は真円にせず、共通クロムの角丸 10 px 枠を使う。Phase だけ真円ホバー枠に変える場合も、まず共通クロム全体への影響を確認する。
ラベルと内部表記画面上のラベルは Φ。URL / シリアライズ / 内部表記は既存の P / P(θ) を維持し、共有リンクや保存済み回路との互換性を壊さない。
パラメータ表示方針θ の現在値はゲート本体へ埋め込まず、既定角 π/2 を含めて本体外側の角度ラベルとして表示する。40 px 本体では Φ の識別性を優先し、編集フォームはポップオーバー側で扱う。
