状態ベクトルパネル — リサイズハンドル (G 案ベース・内側配置)

元の G 案 (state-panel-handle-mockups.html) の L 字ブラケット ⌜ ⌝ ⌞ ⌟ をパネル内側に padding 3px で配置。外側コーナーは panel R (16px) − padding で丸めて panel の角に沿わせる。上 2 つはヘッダー帯 (sky-500) 内側、下 2 つは白パネル上。色は背景に追従: 上 idle sky-200 / drag white、下 idle zinc-300 / drag zinc-600。識別子は「L 字の形」、色は地に合わせる設計。

padding 2px (R = 14px)

ほぼ角ぴったり

パネル R にほぼ一致するくらい曲率がきつい弧。角を最大限つかみやすいが、ハンドルがパネル枠と一体化して見えて「これがハンドル」と気づきにくい時がある。

3 qubits 8 × 1 = 8 states
padding 3px (R = 13px / 推奨)

角から 3px

角からわずかに離して、ハンドルが独立した「掴める要素」だとわかる距離。外側コーナーが panel R に自然に沿い、上 2 つはヘッダー帯の sky-500 にきれいに収まる。これを採用するのがおすすめ。

3 qubits 8 × 1 = 8 states
padding 5px (R = 11px)

角から 5px

角から少し離れた位置。落ち着いた印象になる一方で、3px と比較すると「角を掴む」感が薄れ、ただパネル内に L 字が浮いているように見える。

3 qubits 8 × 1 = 8 states
インタラクティブ — padding 3px

実際にリサイズしてみる

四隅の L 字ブラケットをドラッグするとパネルが縦横にリサイズし、ヘッダー帯をドラッグすると平行移動します。ドラッグ中だけハンドルが zinc-600 に変わります。最小サイズ 200×120、最大 720×480。

3 qubits 8 × 1 = 8 states
上 idle: sky-200 / drag white 下 idle: zinc-300 / drag zinc-600 カーソル: nwse-resize / nesw-resize

仕様まとめ

  • 形状: 10×10px、border 2px、内側 2 辺だけ枠を残した L 字 (⌜ ⌝ ⌞ ⌟)
  • 外側コーナー: panel R (16px) − padding で丸める (padding 3px なら R = 13px)。panel の角に沿う円弧になる
  • 配置: パネル内側。padding 3px が採用候補。上 2 つはヘッダー帯の内側、下 2 つはパネル下端
  • ヘッダー帯: 22 → 28px に拡張 (上ハンドルが収まるように)。左右 padding 28px で text とハンドルが衝突しない
  • 状態: 常に表示、フェードイン/アウトなし、ホバー色変化なし。色は背景に追従: 上 2 つ (sky-500 strip 上) → idle sky-200 / drag white、下 2 つ (white panel 上) → idle zinc-300 / drag zinc-600
  • カーソル: nwse-resize (左上・右下) / nesw-resize (右上・左下)
