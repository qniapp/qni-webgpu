# 決定事項

- Webアプリ: TypeScript + Vite、WebGPUで計算・描画。
- TUIアプリ: Rust、CPUベースのシミュレータ（リッチTUI）。
- 回路フォーマットはWeb/TUIで相互にやり取りできる形にする（TUI→Web／Web→TUI）。
- 回路の共有フォーマット: YAML（人間が読みやすく、機械は必要に応じてJSONへ変換）。
- 回路YAMLにはバージョン番号を含め、将来の互換性を確保する。
- リポジトリ構成: monorepo（apps/web, apps/tui）。
- Webのパッケージマネージャ: pnpm（monorepo運用に適していて現在も活発）。
- Web UI: フレームワークなし（素のTypeScript/HTML/CSS）。
- PoC UI: 起動時は回路を空のままにし、状態ベクトルは `|0>` とする。
- PoC表示: Web/TUIともにテキスト表示のみ（図やグラフは無し）。
- PoC表示: 複素数ベクトルのみを表示する（説明文は無し）。
- PoC表示: 回路の内容も表示する。
- PoC表示: 回路は量子ビットの線とX/Hゲート箱を表示する。
- PoC表示: 量子ビットは2本（q0, q1）を表示する。
- PoC表示: Web/TUI両方で回路図を表示する（TUIはリッチ表示）。
- PoC表示: 回路の時間方向は左→右。
- PoC表示: PoC回路図は1本線にX/H箱を並べるだけ。
- PoC表示: 各ワイヤのゲート配置は一定間隔のスロットにスナップする。
- PoC表示: スロットの左端はワイヤ左端からゲート幅の1/2、間隔はゲート幅の1/2空ける。
- PoC表示: 状態ベクトルは回路上に置かれたゲートを左から順に適用した結果とする。
- PoC表示: Webの回路図表示はWebGPUで描画する。
- PoC表示: Webの状態ベクトル表示もWebGPUで描画する。
- PoC表示: TUIの状態ベクトルはテキスト表示。
- WebGPU: Webの文字描画は固定ビットマップフォント方式で行う。
- WebGPU: ビットマップフォントは必要文字だけ自作する。
- WebGPU: ビットマップフォントは 8x8 サイズを使う。
- WebGPU: 文字描画はフォントテクスチャを使う。
- WebGPU: フォントテクスチャはASCII順に配置する。
- WebGPU: フォントテクスチャは1枚にまとめる。
- WebGPU: ゲートラベルはSVGをビルド時にPNGへ変換し、PNGからテクスチャを作る。
- WebGPU: 回路図と文字は同一の描画パスで描く。
- WebGPU: PoCの描画解像度は画面サイズに合わせる。
- WebUI: レイアウトの基準単位は `1rem = 32px`。
- WebGPU: 文字描画の最小文字セットは `0-9`, `+`, `-`, `.`, `i`, `(`, `)`, `[`, `]`, `,`, 空白, `X`, `H`, `Y`, `Z`, `S`, `T`。
- PoC表示: TUIの回路図はリッチ表示。
- TUI: リッチ表示は `ratatui` を使う。
- PoC仕様: 初期状態は `|0>` 固定。
- PoC仕様: 初期状態は `|00>` 固定（2量子ビット）。
- PoC仕様: WebGPU計算は `f32` を使う。
- PoC仕様: 状態ベクトルのゲート適用はWebGPUのCompute Shaderで行い、CPUはテスト用の読み戻しのみ。
- PoC仕様: TUI計算は `f64` を使う。
- PoC表示: 状態ベクトルは複素数を符号付きの固定小数（小数6桁・切り捨て）で配列表示する（例: `[(+1.000000+0.000000i), (+0.000000+0.000000i), (+0.000000+0.000000i), (+0.000000+0.000000i)]`）。
- PoC表示: 複素数の丸めは行わない。
- PoC表示: 状態ベクトルは基底のインデックス順（`|0>`, `|1>`）で表示する。
- 回路YAML（最小PoC）: `operations` を持つ。`operations` は命令リストで `gate` と `targets` を使う。
- 回路YAML（最小PoC）: ゲート集合は `H`, `X`, `Y`, `Z`, `√X`, `S`, `S†`, `T`, `T†`。
- 回路YAML（最小PoC）: 測定は扱わない（古典ビット/レジスタも不要）。
- 回路YAML（最小PoC）: `qubits` は省略可でデフォルト2量子ビット。
- 回路YAML（最小PoC）: `targets` のインデックスは 0 始まり。
- 回路YAML（最小PoC）: `gate` は文字列で表す。
- 回路YAML（最小PoC）: `operations` の配列順が実行順（先頭が最初）。
- 回路YAML（最小PoC）: `targets` は1要素のみ。
- 回路YAML（最小PoC）: 各 `operation` は `gate` と `targets` を必須とする。
- 回路YAML（最小PoC）: `operations` の要素数に上限は設けない。
- 回路YAML（最小PoC）: `operations` は空配列でもよい。
- 回路YAML（最小PoC）: `operations` は必須。
- 回路YAML（最小PoC）: `gate` は大文字（`X`, `H`, `Y`, `Z`, `S`, `T`）を使う。
