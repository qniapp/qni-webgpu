# 決定事項

- Webアプリ: Rust（egui/eframe + wgpu）。状態ベクトル計算・描画は WebGPU（Compute/Fragment）で行い、CPU への読み戻しはテスト時のみ。
- TUIアプリ: Rust、CPUベースのシミュレータ（リッチTUI）。
- 回路フォーマットはWeb/TUIで相互にやり取りできる形にする（TUI→Web／Web→TUI）。
- 回路の共有フォーマット: YAML（人間が読みやすく、機械は必要に応じてJSONへ変換）。
- 回路YAMLにはバージョン番号を含め、将来の互換性を確保する。
- リポジトリ構成: monorepo（apps/egui-web, apps/tui, apps/mcp-qni）。
- Webのパッケージマネージャ: pnpm（monorepo運用に適していて現在も活発）。
- Web UI: egui（eframe）。
- PoC UI: 起動時は回路を空のままにし、状態ベクトルは `|00>` とする。
- PoC表示: 回路の内容も表示する。
- PoC表示: 回路は量子ビットの線とゲート箱を表示する（`H/X/Y/Z/√X/S/S†/T/T†/P/Rx/Ry/Rz/SWAP`）。
- PoC表示: `P/Rx/Ry/Rz` の角度はデフォルトで `π/2` を使う。
- PoC表示: 量子ビットは2本から開始し、ドラッグ中は空の1本を追加して最大16本まで表示する。
- PoC表示: Web/TUI両方で回路図を表示する（TUIはリッチ表示）。
- PoC表示: 回路の時間方向は左→右。
- PoC表示: PoC回路図は2本のワイヤにゲート箱を並べるだけ。
- PoC表示: 各ワイヤのゲート配置は一定間隔のスロットにスナップする。
- PoC表示: スロットの左端はワイヤ左端からゲート幅の1/2、間隔はゲート幅の1/2空ける。
- PoC表示: 状態ベクトルは回路上に置かれたゲートを左から順に適用した結果とする。
- PoC表示: Webの回路図表示はWebGPUで描画する。
- PoC表示: Webの状態ベクトル表示もWebGPUで描画する。
- PoC表示: TUIの状態ベクトルはテキスト表示。
- WebGPU: egui/wgpu の標準レンダラーを使う。
- WebUI: レイアウトの基準単位は `1rem = 32px`。
- PoC表示: TUIの回路図はリッチ表示。
- TUI: リッチ表示は `ratatui` を使う。
- PoC仕様: 初期状態は `|00>` 固定（2量子ビット）。
- PoC仕様: Webの状態ベクトル計算は WebGPU の `f32` 実装で行う（CPU への読み戻しはテスト時のみ）。
- PoC仕様: TUI計算は `f64` を使う。
- PoC表示: 状態ベクトルは基底ごとの円で表示する。q0しか使っていない場合は2つの円に縮小する。
- PoC表示: パレットと状態ベクトルは固定オーバーレイにし、回路エリアは縦スクロール可能にする。
- PoC表示: 状態ベクトルの円は画面幅に合わせて折り返し、各行の数を揃えた上で必要に応じて縮小して全体が画面内に収まるようにする。
- PoC表示: 状態ベクトルの円は数が増えるほど縮小し、画面を専有しないように最大高さを制限する。
- PoC表示: 状態ベクトルのパネルはドラッグ可能なハンドルを持つ。
- PoC表示: 状態ベクトルの詳細ツールチップは GPU 側の文字描画が整うまで無効（TODO）。
- PoC表示: 状態ベクトルのツールチップのアイコンは qni の amplitude/probability/phase を踏襲予定（TODO）。
- PoC表示: 円の塗りつぶし面積で確率を表現する。
- PoC表示: 振幅が 0 の基底は円の枠線を灰色にする。
- PoC表示: 位相は円内の針で表示する（詳細ツールチップは現在無効）。
- PoC表示: 状態ベクトルは `q0` を最下位ビットとした順（`|00>`, `|01>`, `|10>`, `|11>`）で表示する。
- 回路YAML（最小PoC）: `operations` を持つ。`operations` は命令リストで `gate` と `targets` を使う。
- 回路YAML（最小PoC）: ゲート集合は `H`, `X`, `Y`, `Z`, `√X`, `S`, `S†`, `T`, `T†`, `P`, `Rx`, `Ry`, `Rz`, `SWAP`。
- 回路YAML（最小PoC）: 測定は扱わない（古典ビット/レジスタも不要）。
- 回路YAML（最小PoC）: `qubits` は省略可でデフォルト2量子ビット。
- 回路YAML（最小PoC）: `targets` のインデックスは 0 始まり。
- 回路YAML（最小PoC）: `gate` は文字列で表す。
- 回路YAML（最小PoC）: `operations` の配列順が実行順（先頭が最初）。
- 回路YAML（最小PoC）: `targets` は1要素のみ。
- 回路YAML（最小PoC）: 各 `operation` は `gate` と `targets` を必須とする。
- 回路YAML（最小PoC）: `operations` の要素数に上限は設けない。
- 回路YAML（最小PoC）: `operations` は空配列でもよい。
- 回路YAML（最小PoC）: `operations` は必須。
- 回路YAML（最小PoC）: `gate` は大文字（`X`, `H`, `Y`, `Z`, `S`, `T`）を使う。
