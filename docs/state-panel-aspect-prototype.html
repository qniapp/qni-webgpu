状態ベクトルパネル — A+D 案 動くプロト

A 案 (ホイール) + D 案 (popover) の合せ技。Qubit スライダーで 1〜32 を試せます。寸法テキスト 16 × 4 = 64 states の上で ホイール 1 段ずつ aspect 変更 / クリック で全候補 popover (32 qubit で 33 行、スクロール対応)。

6 (64 states)
6 qubits 16 × 4 = 64 states ▾

操作:

  • ホイール上 寸法テキスト上で → cols 減 / rows 増 (縦長へ)
  • ホイール下 寸法テキスト上で → cols 増 / rows 減 (横長へ)
  • クリック 寸法テキスト → popover で全候補を表示。クリックで選択 / もう一度クリックで閉じる
  • ESC でも popover を閉じる
  • Popover 内は max-height 340px でスクロール (32 qubit = 33 行で必須)

表記: 数字が 4 桁を超えるときは 2n 形式 (32 qubit だと 65536 × 65536 は OK だが 2147483648 は 231)。
