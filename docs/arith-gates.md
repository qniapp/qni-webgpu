# 算術ゲート

インクリメントゲート `+1` とデクリメントゲート `−1` は、範囲内のワイヤを 1 つの整数レジスタとみなして 1 を加算・減算する。Quirk と同じ ID で回路 JSON と URL に保存する。パレットでは 1 行目の回転ゲートの右隣に配置する。既存のパレット幅と既存ゲートの位置は変えない。

## 動作

範囲の大きさを n とすると、インクリメントは 2^n を法として 1 を加え、デクリメントは 1 を引く。範囲の一番上のワイヤを最下位ビットとするリトルエンディアンで値を読む。最大値 2^n − 1 に 1 を加えると 0 に戻り、0 から 1 を引くと 2^n − 1 になる。

どちらも計算基底の置換であり、振幅に位相を付けない。たとえば n = 3 のインクリメントは、値 k の基底状態の振幅を値 (k + 1) mod 8 の基底状態へ移す。デクリメントはその逆変換である。

| 操作 | 例 (n = 3) |
| --- | --- |
| インクリメント | 0 → 1、3 → 4、7 → 0 |
| デクリメント | 1 → 0、4 → 3、0 → 7 |

## 回路 JSON と範囲の変更

シリアライズ ID は `inc1`〜`inc16` / `dec1`〜`dec16` で、数字が範囲の大きさを表す。数字のない `inc` / `dec` や、`inc0` / `inc17` など 1〜16 の外の数字は算術ゲートとして読み込まない。

パレットから置いた直後の範囲は 1 ワイヤである。QFT と同じく伸縮ハンドルで範囲を変えられる。範囲は 16 ワイヤまでで、レジスタの残りのワイヤ数を超えない値に切り詰める。

## 同じ列の制御

同じ列の Control / Anti Control は算術ゲート全体の外部制御になる。制御条件を満たす基底状態だけで加算・減算を行い、満たさない基底状態はそのまま残す。

範囲内の行にある制御記号 (`•` / `◦` / Z Detect-Control-Reset) は、QFT と同じく外部制御から除外する。伸縮可能なブロックの範囲内にあるパリティ制御も除外する。

列内では、ほかのゲートとの順序を次のように決める。

1. 通常の対象ゲートと `Swap` を先に適用する。
2. 算術ゲートと QFT / QFT† を開始行の上から下へ順に適用する。編集時の配置順には依存せず、Qiskit 実行と同じ順序になる。
3. 測定と表示ブロックによる取得を行う。

対象範囲が重ならず、相互の制御もないゲートどうしは可換である。ただし、あるゲートの範囲内の行が別のゲートの外部制御になっている場合は、適用順が結果に現れる。

## GPU 実装

計算は計算シェーダ `apps/web/src/gpu/shaders/arithmetic.wgsl` で行う。各スレッドは出力側の基底状態 1 つを担当し、範囲内の値から加算量を引いた値の入力振幅を読み込む。逆置換で振幅を集めるため、入力と出力には別の状態バッファを使い、ピンポンで切り替える。算術ゲート 1 つにつき 1 回のディスパッチで済む。

パラメータは `var<uniform>` で渡し、`u32` 8 個の 32 バイトである。

| フィールド | 内容 |
| --- | --- |
| `state_count` | 状態ベクトルの要素数 |
| `target_shift` | 範囲の一番上のワイヤのビット位置 |
| `target_mask` | 範囲の大きさ分のビットマスク。シフト前の値を入れる |
| `amount` | 加算量。インクリメントは `1`、デクリメントは −1 を `u32` で巡回させた `u32::MAX` |
| `control_mask` / `control_value` | 外部制御の条件 |
| `_pad0` / `_pad1` | 予約。将来の加算量入力レジスタ用 |

本番経路では CPU で量子状態を計算せず、GPU から CPU への読み戻しもない。

## 外部 Qiskit 実行

外部 GPU 実行でも同じ ID を受け付ける。インクリメントは、範囲の最上位ビットから最下位ビットへ順に、そのビットより下位の範囲内ビットがすべて 1 であることを制御とする多重制御 X を適用する。外部制御と外部反制御もすべての多重制御 X に付ける。デクリメントは同じ操作を最下位ビットから逆順に適用する。各操作は厳密な多重制御 X なので、位相のずれは生じない。

基底追跡は保守的に扱う。外部制御が確実に不成立と分かる場合を除き、範囲内のワイヤを不定とみなす。このため、算術ゲートの後の書き込みゲートは、事前の基底追跡で安全に変換できなければ失敗する。

Z Detect-Control-Reset の行が算術ゲートの範囲と重なる場合は、QFT と同じ範囲の検査で拒否する。

## 対応しないもの

- 条件付きの `inc3<a` など。条件を付けられるゲートの一覧は変更していない。
- Quirk の `+=A` など、入力レジスタ A を使う算術ゲート。入力レジスタ A の仕組みがないため対象外とする。

## 表示

パレットと回路のアイコンは、現在 `+1` / `−1` の文字で描く仮のものである。描画は `apps/web/src/icons/gate_glyphs.rs` の `draw_increment_icon` / `draw_decrement_icon` にまとめてあり、専用のアイコンができたらこの 2 関数だけを差し替える。パレット上の安定 ID は `+1` が 36、`−1` が 37 である。
