外部 GPU 実行モード · UI モック · 設計レビュー用

Local / GPU モード切替

量子ビット数による自動切替はしない。 ユーザーが Local と GPU を明示的に選ぶ。 現在どちらにいるかは常に上部ツールバーで見える。 Local では 17 量子ビット目を追加できない。GPU で 17 量子ビット以上の回路を開いている間は、 Local に戻れない。配置は A 案 (上部ツールバー) に確定済みで、 本書では ツールバー内の組み方を 4 案で詳細化し、A-3 を採用する。

参考: large-gpu-mode-design.html · IBM Quantum Composer の Run / Backend 配置を流用 (右端で 1 ユニット)。

§ 01 上部ツールバー — 詳細案

ツールバーは両モードで常に同じ形でなければならない。 「GPUで実行」ボタンは GPU モードでしか意味を持たないのでツールバーには入れない (GPU バナー側に置く)。ツールバーに乗るのは 量子ビット数 · 直近ステータス · Local/GPU セグメント の 3 要素のみ。並び・整列・分離線をどう組むかで読み取りやすさが変わる。3 案を比較して A-3 を採る。

A-1 · ミニマル / メタ + トグルのみ
28 量子ビット Local GPU

最小要素。視線は左 (量子ビット数) → 右 (モード) の 2 点に集中する。

直近の実行結果が古いのか・完了しているのかが、下にスクロールしないと分からない。

A-2 · モードを中央に寄せる
28 量子ビット Local GPU 外部 GPU · 完了 3.2 s

最重要 (モード) を視覚中心に置き、左右に文脈とステータスを振り分けてシンメトリー。

画面幅が変わると中央位置がずれて、目が泳ぐ。狭い画面ではステータス文が右端から落ちる。

A-3 · 左にメタ + 直近ステータス / 右にトグル 採用
28 量子ビット 外部 GPU · 完了 3.2 s · 4,096 試行 Local GPU

直近の実行ステータスをツールバーに常時表示できる → 編集中も「いま結果は古い / 完了している / 失敗中」がスクロールせず分かる。

構造が両モードで完全に同じ。Local モードではステータス文言が「Local · 触ったら即時更新」に変わるだけ。

ステータス文字列がトグルに干渉しないよう、最大幅と省略表示を決める必要がある。

採用: A-3。両モードで形が一致し、編集中も直近実行ステータスが見える。 実行ボタン (▶GPUで実行) は GPU バナー側に置き、GPU モードでだけ現れる。 app 名 (qni-webgpu) はブラウザのタブで分かるのでツールバーからは省略する。

§ 02 トグル本体 — 形状の検討

ツールバーの中央にあるセグメンテッドコントロール (Local | GPU) を実寸で並べて比較する。 装飾的だったドットは外した (役割がなく情報が冗長になっていた)。 アクティブ表現は「色面塗り + paper 文字 + 太字」の 3 要素が共通で、残るのは 角丸の強さ・トラックの見え方。3 案を見て T-1 を採用する。

T-1 · 角丸 8 px / paper トラック 採用

Local GPU GPU 選択中

既存 UI の角丸 (palette card 12 px / box-border 6 px) と整合。やや角張った形でツールバー要素として馴染む。

paper トラック + ui-2 hairline 枠で「触れる場所」がはっきり。Flexoki の表面層と同じ語彙。

T-2 · 完全なピル形状 (radius 999 px)
Local GPU Local 選択中
Local GPU GPU 選択中

switch / pill control 感が出てモード切替らしさが強まる。「ON/OFF」の比喩が分かりやすい。

UI の他の要素 (gate body radius 6 / panel 14) と角丸スケールが揃わず、唯一だけ丸くて浮く。

T-3 · トラックなし / 下線でアクティブ
Local GPU Local 選択中
Local GPU GPU 選択中

最も静か。ツールバーが視覚的に重くならない。

「クリックできるコントロール」だと一目で分からない。ボタンよりタブに見えるので、モード切替の意味合いが弱まる。

採用: T-1。Flexoki の角丸スケール (6–14 px) と整合する。 アクティブの色は 「GPU の ON / OFF」 比喩を採る: Local = OFF (GPU を使わない) → 無彩色 tx-2、 GPU = ON (外部 GPU を有効化) → アクセント blue-600。 iOS / macOS の toggle switch と同じ意味づけで、色そのものが 「いま外部 GPU が起動しているか」を伝える。

§ 03 実装プロトタイプ — 動く T-1 トップバー

T-1 を実際に押して切り替えられる状態にしたもの。アクティブ側の塗りは 単一のサムとして実装してあり、選択を変えると 位置 + 幅 + 色 (tx-2 ↔ blue-600) がスプリング調のカーブで なめらかに補間される (iOS の UISegmentedControl 風)。Codex 実装の参照として使う。 クリック / Enter / Space で切替、左右矢印キーで移動、フォーカスリングは Flexoki の blue-600 で半透明。prefers-reduced-motion: reduce の環境ではアニメーションは無効化。

(2) GPU バナーを表示する
(3) 自動再計算を停止する
GPU → Local で全部逆。遷移はすべてユーザー操作のみ。

§ 08 明確な非目標

— 非目標 1

量子ビット数による自動切替

17 量子ビットになった瞬間に勝手に GPU へ切り替えない。Local では 17 量子ビット目を追加できず、GPU で 17 量子ビット以上なら Local へ戻れない。モード変更は常にユーザーが選ぶ。

— 非目標 2

全状態ベクトル / 全確率分布

2N 件の振幅・確率を返す API は持たない。GPU モードの返却は測定ヒストグラム / 周辺分布 / 指定振幅 / 観測量に限定。

— 非目標 3

CPU フォールバック

GPU 実行サーバーが落ちたときに CPU で代替計算しない。明示的なエラーとして表示し、再実行を待つ。
