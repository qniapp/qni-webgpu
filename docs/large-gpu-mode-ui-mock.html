§ 04 明確な非目標 — 画面に出さないもの

30 量子ビット級では全状態ベクトルが 8 GiB を超え、ブラウザに送れない。 下記はあえて画面に出さない項目。

— 非目標 1

全状態ベクトル表示

2N 個の振幅と位相を全部描く表示はしない。30 qubit で 8 GiB、JSON 化すれば 24 GiB 級に膨らむ。

— 非目標 2

厳密な全確率分布

確率値だけでも 2N 件。30 qubit の float32 で 4 GiB。既定タブでは出さない。試行ヒストグラムで代替。

— 非目標 3

CPU フォールバック

外部 GPU が落ちたときに CPU で代替計算しない。実行サーバー不在は明確なエラーとして表示し、再実行を待つ。
