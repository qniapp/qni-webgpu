GridCell 実装仕様

行優先（row-major）グリッドのセル位置を、裸の usize 算術ではなく GridCell という値オブジェクトで扱うための仕様。 1 次元のセル番号と 2 次元の桁・行の往復変換（index = row * cols + col とその逆）を 1 か所へ集約し、桁と行の取り違えを型で防ぐ。

§ 01 背景と目的

振幅表示ブロック・密度行列表示ブロック・状態ベクトルパネルのセルは、いずれも左上を起点に桁（列）方向へ進み、右端で次の行へ折り返す行優先グリッドで並ぶ。 1 つのセルは、行優先の通し番号（index = row * cols + col）と、桁・行の組（col = index % cols / row = index / cols）の 2 つの見方を行き来する。

この往復変換が現状は複数の経路へ裸の usize 算術として散らばっている。 順変換（桁・行 → 通し番号）は layout/geometry.rs の振幅・密度のセル番号算出と、密度行列セルの読み戻し（gpu/readback.rs）にあり、逆変換（通し番号 → 桁・行）は振幅ホバー円の中心算出（render/circuit_gates.rs）と状態パネルポップアップのセル中心算出（render/state_panel_popup/cell/geometry.rs）にある。 桁数（cols）と行数（rows）はいずれも usize なので、現状はコンパイラが桁と行の取り違えや、剰余と商の取り違えを検出できない。

GridCell は「行優先グリッド上のセル位置（桁・行）」だけを表す値オブジェクトにする。 通し番号との往復変換を from_index / to_index に閉じ込め、row * cols + col やその逆を呼び出し側へ書かない。 これにより、ドメイン駆動設計（DDD）の観点で重要な不変性・等価性・型の一貫性を、グリッドのセル位置へ適用する。

  • 行優先の通し番号と桁・行の往復は from_index / to_index に集約し、% cols / / cols / row * cols + col を呼び出し側へ書かない
  • 桁（col）と行（row）を型のフィールドとして区別し、同じ usize として取り違えない
  • GPU の WGSL シェーダ内に現れる同じ行優先規約は、シェーダ側で完結させるためこの値オブジェクトの対象外とする

§ 02 ドメインモデル

型名GridCell
配置先apps/web/src/grid_cell.rs を新設し、lib.rs から mod grid_cell; で公開する（QubitBit と並ぶ、サブシステム横断の基盤型）
意味行優先グリッド上の 1 セルの位置。左上を (col, row) = (0, 0) として、桁は右へ、行は下へ増える
保持する値桁 col: usize と行 row: usize。フィールドは非公開にし、col() / row() で読む
性質値オブジェクト。等価性・ハッシュを内部値（桁・行の組）で定める。同一性は持たない
桁数の出どころ振幅は amplitude_grid_dims(span) の桁数、密度行列は dim = 1 << span、状態パネルは layout.columns()。いずれも 1 以上で、GridCell へ cols として渡す
対象範囲振幅・密度のセル番号算出（順変換）、振幅ホバー円とポップアップのセル中心算出（逆変換）、密度行列セルの読み戻しのセル番号（順変換）
対象外セルのピクセル座標（egui::Pos2 / egui::Rect）、桁数・行数そのもの（グリッドの寸法）、GPU の WGSL シェーダ内の行優先算術（シェーダで完結させる）

想定 API

#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub(crate) struct GridCell {
    col: usize,
    row: usize,
}

impl GridCell {
    pub(crate) const fn new(col: usize, row: usize) -> Self;

    /// 行優先の通し番号から桁・行を復元する（`col = index % cols` / `row = index / cols`）。
    pub(crate) const fn from_index(index: usize, cols: usize) -> Self;

    pub(crate) const fn col(self) -> usize;
    pub(crate) const fn row(self) -> usize;

    /// 行優先の通し番号へ変換する（`row * cols + col`）。
    pub(crate) const fn to_index(self, cols: usize) -> usize;
}

cols は呼び出し側が 1 以上を保証する（グリッド寸法が max(1) 済み、または 1 << span で必ず 1 以上）。 不変条件を型へ閉じ込めるのは桁・行の組であり、桁数 cols は変換ごとに引数として渡す。 col() / row() はピクセル座標を求める直前など、境界層へ出るときだけ使う。

§ 03 DDD 上の性質

性質仕様禁止事項
不変性 生成後に桁・行を変更しない。別のセルが要るときは新しい GridCell を作る 公開フィールド、set_col / set_row、&mut usize を返すメソッドを作らない
自己検証 行優先の往復変換を from_index / to_index に集約し、剰余・商・乗算の式を 1 か所に閉じ込める 呼び出し側で index % cols / index / cols / row * cols + col を重複実装しない
等価性 桁・行の組で比較する。別々に生成した同じ桁・行の GridCell は等しい ピクセル座標や生成元でセル位置の等価性を判定しない
型の一貫性 セル位置を受け渡す箇所は GridCell を使い、桁と行を別々の usize として裸で持ち回らない 桁・行の組を新しく (usize, usize) のタプルや 2 つの usize 引数で追加しない

§ 04 組み込み方

順変換（桁・行 → 通し番号）

layout/geometry.rs の amplitude_cell_index_at と density_matrix_cell_index_at は、カーソル位置から桁・行を求めた後に (row * cols + col) as u32（密度行列では cols を dim とする）でセル番号を返している。 この末尾の式を GridCell::new(col, row).to_index(cols) as u32 に置き換える。

gpu/readback.rs の密度行列セル読み戻し（read_density_matrix_cell_impl、wasm 専用のテストハーネス経路）にある row as usize * dim + col as usize も、GridCell::new(col as usize, row as usize).to_index(dim) に置き換える。 境界チェック（row >= dim / col >= dim）は変換とは別の関心事なので、そのまま残す。

逆変換（通し番号 → 桁・行）

render/circuit_gates.rs の amplitude_hover_circle にある col = outcome % cols / row = outcome / cols は、let cell = GridCell::from_index(outcome, cols); にし、ピクセル中心を求める箇所で cell.col() / cell.row() を使う。 render/state_panel_popup/cell/geometry.rs の cell_center_for にある col = display_index % cols / row = display_index / cols も同様に GridCell::from_index(display_index, cols) へ置き換える。

§ 05 境界と変換規則

入口 / 出口形式変換備考
ホバー・選択通し番号 u32（GPU 表示インデックス / 結果インデックス）GridCell::from_index(index, cols)桁数 cols はグリッド寸法から渡す
セル番号の書き出し通し番号 u32cell.to_index(cols) as u32カーソルから求めた桁・行を 1 つの番号へ畳む
ピクセル座標egui::Pos2 / egui::Rectcell.col() / cell.row() を取り出して座標式へ渡す座標計算自体は値オブジェクトの外
GPU シェーダWGSL 内の行優先算術変換しないGPU 側で完結させる（密度行列表示ブロック ほか）

桁数 cols はグリッドの寸法であり、セル位置の一部ではない。 GridCell は桁・行の組だけを持ち、cols は往復変換のたびに引数で受け取る。

§ 06 移行方針

  1. GridCell を apps/web/src/grid_cell.rs に追加し、lib.rs から mod grid_cell; で公開する
  2. 順変換の 3 か所（amplitude_cell_index_at / density_matrix_cell_index_at / read_density_matrix_cell_impl）を to_index へ置き換える
  3. 逆変換の 2 か所（amplitude_hover_circle / cell_center_for）を from_index ＋ col() / row() へ置き換える
  4. 行優先の往復算術（% cols / / cols / row * cols + col）が CPU 側の Rust に残っていないことを rg で確認する（WGSL シェーダ内は対象外）

後方互換の別名や古い入口は残さない。 桁・行の組を usize のタプルや 2 引数で受け渡す関数を新設しない。

§ 07 受け入れ条件

  1. 桁・行を保持できる — GridCell::new(1, 2) の col() が 1、row() が 2 になることを確認する
  2. 通し番号から復元できる — 桁数 3 で GridCell::from_index(7, 3) が桁 1・行 2 になることを確認する
  3. 通し番号へ畳める — 桁数 3 で GridCell::new(1, 2).to_index(3) が 7 になることを確認する
  4. 往復で元へ戻る — 桁数 4 で from_index(11, 4) を to_index(4) したとき 11 に戻ることを確認する
  5. 先頭セルは原点 — 桁数 3 で GridCell::from_index(0, 3) が桁 0・行 0 になることを確認する
  6. 等価性が値で決まる — 別々に生成した GridCell::new(1, 2) 同士が等しいことを確認する
  7. CPU 側の行優先算術が残らない — 振幅・密度のセル番号算出、振幅ホバー円、状態パネルポップアップ、密度行列セル読み戻しが GridCell を使うことを確認する
