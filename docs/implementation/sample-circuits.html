9 本のサンプル回路の読み方

サンプルを開いたら、まず回路ブロックのラベルで処理のまとまりを読み、表示ブロックで状態や確率を見比べる。

共通の読み方

青い上下罫線の淡い帯が回路ブロック。全ワイヤにまたがり、上下に同じ英語のラベルを表示する。ブロック間の空列は区切りで、帯も空列も計算を変えない。

一番上の q0 が最下位ビット（LSB）。値 k は q0 + 2·q1 + 4·q2 + … で数える。ビット列 |q2 q1 q0⟩ では右端が q0 になる。

  • Bloch は 1 量子ビットのブロッホ球表示ブロック。球の向きで状態を比べる。
  • ProbabilityN は N 量子ビットの確率表示ブロック。各値の確率を見る。1 量子ビットでは接尾辞なしの Probability。
  • AmpsN は振幅表示ブロック。円の大きさは振幅の絶対値、針は位相を示し、確率は絶対値の二乗。

表示ブロックは状態を変えない。同じ列の制御は表示の条件にもなるため、遅延選択量子消しゴムの sort by q0,q1 にある 4 個の Probability7 以外は専用の列に置いている。

このページの回路図は配置を示す静的な図で、表示ブロックの箱は計算結果ではない。以下の値はアプリでサンプルを実行したときの読み方。Bell の Amps2 と GHZ の Amps3 は 2 列幅なので、直後の余白列も帯に含めている。

§ 01 Bell 状態（Bell state）

H で q0 を重ね合わせにし、CNOT でもつれを作る最小の例。

回路ブロック役割と表示の読み方
superpositionH の後の Bloch は +x（|+⟩）を向く。
entangleAmps2 の |00⟩ と |11⟩ にだけ +1/√2 の振幅がある。

§ 02 GHZ 状態（GHZ state）

Bell 状態をもう 1 量子ビットへ広げ、3 本が全部 0 か全部 1 になる。

回路ブロック役割と表示の読み方
superpositionBell と同じく、H の後の Bloch は +x を向く。
entangleCNOT を 2 回使う。Amps3 の |000⟩ と |111⟩ にだけ +1/√2 の振幅がある。

§ 03 量子テレポーテーション（Quantum Teleportation）

共有したもつれと 2 ビットの測定結果を使い、q0 の状態を q2 へ移す。

回路ブロック役割と表示の読み方
Bell pairq1・q2 にもつれを用意する。
messageH と T でメッセージを作り、Bloch で表示する。
Bell measurementq0・q1 を測定し、2 ビットの古典情報を得る。
correction測定値に応じて X と Z で補正する。
receivedq2 の Bloch は message と同じ (1/√2, 1/√2, 0)。測定結果はランダムでも一致する。

§ 04 超高密度符号化（Superdense Coding）

共有したベルペアを使い、1 量子ビットを送るだけで 2 古典ビットを伝える。送信ビットは 11 に固定している。

回路ブロック役割と表示の読み方
Bell pairq3・q4 にもつれを作る。
distributeSwap でアリスとボブへ配る。
messageq0・q1 の Probability2 は 11（値 3）が 100 %。
encodeZ と X で 2 ビットを符号化する。
send符号化した 1 量子ビットを送る。
decode復号後の q4・q5 の Probability2 も 11 が 100 %。q0 ↔ q4、q1 ↔ q5 に対応する。

§ 05 4 量子ビットの量子フーリエ変換（QFT 4-qubit）

周期的な入力が、周期に対応する位置のピークへ変わる。

回路ブロック役割と表示の読み方
inputq1–q3 に H を掛け、偶数の値 0・2・…・14 に各 1/8 の確率を持つ周期 2 の入力を作る。Probability4 で確認する。
bit reversalSwap で入力のビット順を反転する。
phase ladderH と制御位相回転 P(π_2)・P(π_4)・P(π_8) のはしごで QFT を実行する。
outputProbability4 は |0⟩ と |8⟩ に各 1/2。16 / 周期 2 = 8 の倍数に集まる。

§ 06 対称性の破れ（Symmetry Breaking）

上の組 Alice¹（q0・q1）と下の組 Alice²（q2・q3）に同じ操作をしても、両者の測定結果は必ずビット反転になる。

回路ブロック役割と表示の読み方
two Bell pairs2 組にもつれを用意する。
swap partnersq1 と q3 を入れ替える。
symmetric ops両組に同じ操作を行う。
outcomes differProbability2 ×2 はどちらも 4 通りが各 25 %。Probability4 は値 3・6・9・12 だけが各 25 %。各組だけでは区別できないが、組み合わせると必ず逆になる。

§ 07 Grover 探索（Grover Search）

32 通りの中で印を付けた |27⟩ の確率を、反復によって高める。

回路ブロック役割と表示の読み方
superposition一様な重ね合わせを作る。Probability5 の |27⟩ は約 3.1 %。
oracle|27⟩ の位相を反転する。
diffuser平均のまわりで振幅を反転する。最初の反復後は約 25.8 %。
iteration 2 / iteration 3 / iteration 4オラクルと拡散を繰り返す。Probability5 の |27⟩ は約 60.2 % → 89.7 % → 99.9 % と増える。表示は初期状態を含めて 5 個。

§ 08 可逆加算（Reversible Addition）

A（q0–q4）を保ったまま B（q5–q9）に足す。5 ビットなので計算は mod 32。

回路ブロック役割と表示の読み方
A=5, B=3入力の Probability5 ×2 は A = 5、B = 3 に確率 1。
B += AX・CNOT・制御 Swap の可逆回路で足し算する。
A=5, B=8出力の Probability5 ×2 は A = 5 のまま、B = 8 に確率 1。

§ 09 遅延選択量子消しゴム（Delayed Choice Eraser）

経路情報を消した場合だけ、選択と経路で仕分けたスクリーンの分布に干渉縞が現れる。

回路ブロック役割と表示の読み方
two slitsq1 の二経路の重ね合わせを q4 と結び、経路情報を残す。
screenq2–q8 に QFT7 を適用する。Probability7 は全 128 通りが 1/128。
erase path?q0 の選択で q1 の基底を変え、経路情報を消す。測定は置かない。
sort by q0,q1左から (q0,q1) = (0,0), (0,1), (1,0), (1,1) の条件付き Probability7。最初の 2 つは平らで各 1/128。(1,0) は周期 32 の縞で、値 8・40・72・104 は 1/64、24・56・88・120 は 0。(1,1) は逆の縞で、値 8 は 0、24 は 1/64。
