qni のデザインは 黒背景 + 白文字で、tooltip としてはハイコントラストで読みやすい一方、Light テーマの中だとやや浮く印象もあります。Flexoki Light の中で違和感のない 4 案を並べます。コンテンツは qni と同じ: |0001⟩ decimal 1 / Amplitude / Probability / Phase。

比較

4 案の比較

案 スタイル 利点 欠点
A — Dark tx + paper qni と同じ、最高コントラスト、即「tooltip だ」とわかる Light テーマ内で stark に見える、視覚的に重い
B — Paper paper + ui-2 border + shadow Flexoki Light に完全になじむ、shadow で elevation が出る、アイコンの blue-600 がアクセント 背景 (bg-2) との差が小さいので shadow に依存
C — Tinted blue-50 + blue-900 色で「state-vector 情報」と意味づけ、上品 青要素が増えすぎてゴチャつく可能性
D — Muted ui (cream) + tx 最も控えめ、Flexoki 色味で全体統一 page との差が小さく tooltip と気づきにくい
E — Headered blue-600 header + paper body state panel ヘッダと色で繋がる、「これは state-vector」とすぐ分かる 青の area が増える、chrome がやや多い
F — Minimal paper + shadow only (no border) もっとも軽量・モダン shadow に完全依存、bg-2 上では elevation が弱い

個人的なおすすめは B 案 (Paper): Flexoki Light の他のカード / popover (palette、state panel、aspect popover) と同じ paper 紙片の手触りで、新しい色を増やさず、shadow で別レイヤだとはっきり示せる。 qni と全く同じ感覚は失われるが Light テーマで一貫します。

共通仕様

  • 表示位置: ホバーした円の上方、円の中央線に対して水平センター。狭い場合 (パネル上端付近) は下方に自動切替。
  • Tail: popup から円へ伸びる小さな三角 (caret)。
  • Anchor 切替: 円から 12〜16px のオフセット、画面端でクランプ。
  • 内容: header "|ABCD⟩ decimal N" + Amplitude / Probability / Phase の 3 行。数値は monospace。
  • アイコン: Q (amplitude) / ◯ (probability) / ∠ (phase) — qni と同じ 3 つ。
