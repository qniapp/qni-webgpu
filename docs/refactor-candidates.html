Model refactor — 一番効く変更の形

PlacedGate の正本を column / wire / span にする。Qni の stepAt() / dropzoneAt() と同じく、pixel は layout の出力か drag preview の一時値だけに閉じ込める。

Before

Pixel drives everything

PlacedGate.pos — 永続 state
nearest_slot_index — 毎回逆算
URL JSON — pos から column 化
GPU linearize — pos から slot bucket
render — pos を直接配置
After

Semantic model drives layout

PlacedGate.column — Qni stepIndex 相当
PlacedGate.wire — Qni dropzone bit 相当
PlacedGate.span — Qni ResizeableSpan 相当
layout.position(gate) — 描画時だけ pixel
DragPreview.pos — pointer 追従の一時値
StepIr — Qni SerializedCircuitStep 相当
