Circuit picker reorder

回路一覧をマウスでつかんで上下にドラッグして並び替える機能。 submenu の Move up / Move down はそのまま残す (キーボード派や 1 段ずつ動かしたい時の代替) ─ ドラッグはマウスでまとめて再配置したい時の primary な手段。ドロップダウンの幅 / 影 / 角丸 / その他の挙動は実装済みの picker と同じ。差分はドラッグハンドル無しの whole-row drag と drop indicator のみ。

§ 01 ドラッグの 3 状態

Idle (普通) → Hover (掴める合図 = cursor: grab) → Dragging (ソースは opacity: 0.35 で薄く残り、ゴースト要素がカーソルに付いて移動)。 Drop indicator は 2 px の blue-600 線で「ここに入る」位置を示す。

§ 02 ドラッグ機構の解剖

ドラッグハンドルは導入しない ─ 行のどこを掴んでも drag に入る。 kebab だけは drag 対象外 (kebab クリックで submenu を開く挙動を維持)。 Drop indicator の位置は「カーソル Y が hovered item の上半分なら 1 つ上、下半分なら 1 つ下」で決まる。 Create new circuit の footer は drag target から除外。

part挙動 / トークン
drag start 行の mousedown + 移動距離 ≥ 4 px で drag 開始 (egui だと response.drag_started() 相当)。閾値以下のクリックは選択 / kebab open など本来の挙動。
cursor 行 hover で grab、drag 中は grabbing。kebab hover では pointer。
source row drag 中は opacity: 0.35 で薄く居残り、レイアウトは動かない (他の行が押し出されない)。
ghost position: fixed のクローンが pointer に追従。shadow-drag + 1° 弱の傾き、bg paper、width は dropdown 内側 (240 - 12 = 228 px)。
移動は Y 軸のみ ─ 横方向にカーソルが動いても ghost.left は drag 開始時の row.left に固定。 横移動を許すと dropdown 列から外れて視覚的に紛らわしいので意図的に抑制。
drop indicator 2 px blue-600 横線。dropdown 内側 left 6 / right 6 のフルワイド。z-index で行より前面。
drop target 判定 カーソル Y が hovered row の rect.center より上 → target = hovered_index、下 → target = hovered_index + 1。source 自身と隣接 (no-op) は indicator を出さない。
kebab 除外 kebab 上の mousedown は drag を開始しない (event を kebab handler に渡す)。kebab は drag handle ではなく submenu trigger。
auto scroll dropdown が scrollable で、カーソルが dropdown rect の上下 24 px 以内に入ったら 60 fps で 6 px/frame スクロール (entries が多い時用、今は entries 少ないので第 1 弾では実装不要)。
release mouseup で entries.splice(src, 1) + entries.splice(adjusted_target, 0, item)。active_id は entry id で保持してるので index ズレなし。Esc 中断 = source 戻し。
submenu との両立 submenu の Move up / Move down は据置 ─ キーボード代替 / 1 段ずつ動かしたい時用。drag は飛ばし移動の primary path。

§ 03 実装プロトタイプ — 掴んで上下に動かす

各行を mouse でつかんで上下に移動 → 2 px の青ライン (drop indicator) が出ている位置で離すと並び替わる。 Esc でキャンセル。kebab は drag されない (クリックすると "kebab clicked" alert)。 Create new circuit は drag 対象外。

§ 04 実装仕様 (Codex 用リファレンス)

既存 picker への差分 — drag-reorder の追加だけ。

  1. 状態 ─ PickerState::Open に drag 中 sub-state を追加: 
    pub(crate) enum DragState {
    Idle,
    Pending { entry_index: usize, started_pos: Pos2 },  // mousedown 直後、まだ 4 px 動いてない
    Active  { entry_index: usize, ghost_offset: Vec2 }, // drag 確定。ghost を painter で描く
}
    Pending → Active への昇格は pointer 移動距離 ≥ 4 px。 Pending 中に mouseup なら通常の click として扱う (select)。
  2. 各 item 行 の egui::Sense::click_and_drag() に変更。 response.drag_started() で DragState::Pending。 response.drag_delta().length_sq() > 16.0 で Active に昇格。 response.drag_released() で drop 実行。 ui.input(|i| i.key_pressed(Key::Escape)) で cancel。
  3. kebab は drag 対象外 ─ kebab 用の inner Response が Sense::click() のままで、その上のクリックは行の drag を起こさない (egui は inner widget のクリックを優先する)。
  4. ghost 描画 ─ egui::Area::new("circuit-picker-drag-ghost") .order(Order::Tooltip) で floating な layer に行のコピーを描く。 Frame は paper bg / radius 6 / Shadow { offset: vec2(0, 6), blur: 16, color: tx \w 40 }。 ghost width = dropdown.inner_width。傾きは Mesh::rotate(-0.017) (≒ -1°) で軽く。
    position は Y 軸のみ追従: 
    let ghost_x = source_row_rect.left();  // drag 開始時の row 左端で固定
let ghost_y = pointer_pos.y - drag.ghost_offset_y;
area.fixed_pos(pos2(ghost_x, ghost_y))
    cursor の X 座標は意図的に無視する。横にずらすと dropdown 列から外れて 視覚的にうるさく、また「上下に並び替える」というアフォーダンスを壊すため。
  5. drop target 計算: 
    let cursor_y = pointer_pos.y;
let mut target = entries.len();  // 末尾デフォルト
for (i, row_rect) in row_rects.iter().enumerate() {
    if cursor_y < row_rect.center().y {
        target = i; break;
    }
}
// source 自身 / 隣接 (target == src || target == src + 1) は no-op。
  6. drop indicator 描画 ─ target が決まったら、 row_rects[target].top() (または末尾なら last_rect.bottom()) の Y 位置に 2 px の青 (blue-600) 横線を painter.rect_filled で描く。 dropdown 内側 left + 6 / right + 6 のフルワイド。source と隣接の場合は描かない。
  7. release で reorder: 
    let mut adjusted_target = target;
if target > src { adjusted_target -= 1; }  // source を抜いた後の index ずれ補正
let entry = library.entries.remove(src);
library.entries.insert(adjusted_target, entry);
library.bump_updated_at();  // 永続化 Codex がこの flag で save
    active_id は entry の id で保持してるので index 変更しても active は同じ entry を指したまま。
  8. Esc で cancel ─ DragState::Active 中の Esc キーで DragState::Idle に戻す。source row の opacity が戻り、ghost が消える。reorder は起こらない。
  9. auto scroll ─ entries 件数が dropdown max-height (320 px) を超えないうちは 本 PR では実装しない。スクロール対応が要る段階で別 PR。
  10. submenu の Move up / Move down は touched しない。 既存実装 (entries の隣接 swap) と drag-reorder は独立で並存。
  11. cursor アイコン: ・行 hover → CursorIcon::Grab
    ・DragState::Pending / Active 中 → CursorIcon::Grabbing
    ・kebab hover → CursorIcon::PointingHand
    ui.output_mut(|o| o.cursor_icon = ...) で設定。
  12. Tests ─ tests/egui-web-circuit-picker-reorder.spec.ts を新規:
    ・3 件目を 1 件目の上にドラッグ → 順序が [3, 1, 2] に
    ・1 件目を末尾にドラッグ → 順序が [2, 3, 1] に
    ・drag 中 Esc → 順序維持
    ・kebab クリックは drag を起こさず submenu を開く (回帰防止)
    Playwright の mouse.down() / mouse.move() / mouse.up() で本物のマウス操作を実行。

Acceptance

  1. 行を mouse で掴んで上下にドラッグできる。drag 中 source は薄く残り、ghost が cursor に付いて移動。
  2. ghost は Y 軸のみ追従。カーソルが横に動いても ghost は dropdown 列のまま (left 固定)。
  3. 2 px の青い drop indicator がドロップ位置に出る。source 自身 / 隣接位置では出ない (no-op)。
  4. release で entries が並び替わる。active な entry の id は変わらない (= active 表示も維持)。
  5. Esc で drag をキャンセル、順序維持。
  6. kebab をクリックしても drag は始まらず、submenu が開く (既存挙動の回帰なし)。
  7. submenu の Move up / Move down は引き続き動く。
  8. cursor が行 hover で grab、drag 中で grabbing。
  9. cargo clippy --target wasm32-unknown-unknown --all-targets -- -D warnings 通過、cargo fmt --check クリーン。
  10. snapshot tests は drag 中の中間 frame をキャプチャしない (flaky 防止) ─ before / after だけ。
