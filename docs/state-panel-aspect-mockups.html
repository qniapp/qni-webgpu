状態ベクトルパネル — 縦横比率切替 UI 案

N qubit の grid は cols × rows = 2^N を満たす限り、(2 のべき) の組合せが自由に取れます。たとえば 6 qubit (64 状態) なら 1×64 / 2×32 / 4×16 / 8×8 / 16×4 / 32×2 / 64×1 の 7 通り。現状は qni の固定テーブルで 16×4 固定ですが、ユーザーが縦横比率を切り替えられるようにしたい。どの UI が良いか、4 つの方向性を並べます。

A 案

寸法テキストをホイール / クリックで操作

ヘッダー帯の 16 × 4 = 64 states 自体をインタラクティブ要素にする。 ホバーすると "⇅" マークが出てクリック可能だとわかり、 ホイール上下で aspect 1 段ずつ変わる。クリックで全候補を popover 表示。ヘッダー帯のスペースをそのまま流用でき UI 追加なし。

6 qubits 16 × 4 = 64 states

テキストにホバー → 背景うっすら / クリックで全候補を popover

B 案

寸法を ‹ 16 × 4 › ステッパー形式

寸法テキストを左右の小さな矢印で囲み、< で縦長へ (cols 半分 / rows 倍)、> で横長へ。 ステッパーが視覚的に明確で、1 アクション = 1 段。両端まで来たら disabled でグレーアウト。 A 案より追加クロムが大きいが、クリック対象が明確。

6 qubits ‹ 16 × 4 = 64 states ›

‹ で縦長 / › で横長。両端で disabled

C 案

ヘッダー帯の下に pip slider 行を追加

ヘッダー帯の下に薄い sky-100 帯を 1 行足し、N+1 個の pip (1×64 / 2×32 / ... / 64×1) を並べる。クリックで一発切替、ドラッグでスライド可能。 全候補が常に見えるのが利点。ただしパネル全体が +22px 高くなる。

6 qubits 16 × 4 = 64 states
1×64 2×32 4×16 8×8 16×4 32×2 64×1

pip クリック / drag で aspect 切替。常時表示

D 案

寸法テキスト → popover (thumbnail 一覧)

A 案の popover を主役にした版。ホイール操作はなく、寸法 = ▾ つきメニューボタンと読ませて、クリックで popover を開く。各候補は 実際の grid 形を thumbnail で表示するので、32×2 がどれくらい横長か直感的に分かる。

比較

4 案の比較

案 操作 利点 欠点 追加 UI
A 寸法テキストにホイール / クリックで popover UI 追加ゼロ、ホイールで一発 ホバーするまで操作可能と分からない なし
B ‹ / › 矢印を 1 クリックずつ 操作対象が明確、1 段ずつで迷いにくい 両端まで遠い (64×1 → 1×64 で 6 クリック) 矢印 ×2
C pip slider 行で全候補が常時表示 全選択肢が一覧、一発切替 パネルが +22px 高くなる / qubit が増えると pip も増えて手狭 slider 行
D 寸法 = ▾ ボタン、popover で thumbnail 一覧 thumbnail で形が直感的、qubit 数によらず一定 UI クリック → popover の 2 ステップ ▾ ヒント

個人的なおすすめは A + D の合せ技: ふだんはホイールでサクッと 1 段ずつ (A 案)、たまにクリックで popover を開いて飛び石遷移 (D 案の thumbnail)。寸法テキストが両モードのトリガーを兼ね、UI クロムは最小限。

共通の前提

  • 選べる aspect は (cols, rows) = (2^a, 2^(N-a)) の N+1 通り (cols/rows ともに 2 のべき)。
  • 切替時に アニメーションするかは別議論。少なくとも初手はジャンプでも OK。
  • aspect とパネル本体のサイズ (リサイズハンドル) は独立。aspect 切替で circle サイズだけが変わる。
  • 1 qubit (2 状態) / 2 qubit (4 状態) のように aspect 選択肢が少ない時は、コントロールを 非表示 にするか disabled にする。
