デザインシステム

qni-webgpu の UI を貫く共通ルールと、画面に現れるコンポーネント仕様を一望するインデックス。 基礎トークン (配色 / タイポグラフィ / 余白) から表示ブロック、量子ゲート、回路エディタ、状態パネルまで、 寸法・色・挙動を 1 つの基準にそろえる。

§ 01基礎トークン (Foundations)

すべてのコンポーネントが共有する横断トークン (配色 / タイポグラフィ / 余白)。

配色 spec

Flexoki Light の中性色 + アクセント色一覧と、実装側 colors.rs の意味別マッピング。
タイポグラフィ spec

Geist / Geist Mono と Tailwind text-xs / text-sm / text-base スケールの使い分け。
スペーシング spec

Tailwind 4px 倍数スケール (spacing-1 = 4 / spacing-2 = 8 / …) の使い方。

§ 02Primitives (横断 UI 部品)

複数のコンポーネントが共有する小さな UI 部品 (primitive)。基礎トークンが「値」なら primitive は「部品」。 chrome (色 / 寸法 / state machine / マイクロインタラクション) を 1 箇所に集約し、各コンポーネント側は policy (使い方の差分) だけを定義する。

リサイズハンドル spec

span を持つ表示ブロック / QFT が共有する上下ドラッグハンドル。cyan-400 ピル形 + バウンス出現。

§ 03表示ブロック (Display blocks)

回路上に「読み取り」だけを行う要素群。ユニタリ変換ではないので厳密にはゲートではなく、`表示ブロック` と呼ぶ。状態ベクトルに影響を与えず、span 内の量子ビットの確率や ブロッホベクトル等を可視化する。

確率表示ブロック spec

span 内の量子ビットを測定したときの outcome 確率を横バーで可視化する表示ブロック。
ブロッホ球表示ブロック spec

単一量子ビットのブロッホベクトル (x, y, z) を透視投影 + 矢印で可視化する表示ブロック。
振幅表示ブロック spec

span 内の量子ビットの複素振幅 (大きさ + 位相) を 1〜16 量子ビット grid で可視化する表示ブロック。
密度行列表示ブロック spec

span 内の量子ビットの局所的な混合状態 (縮約密度行列) を、対角 = 確率 + 非対角 = coupling として 2span × 2span 行列で可視化する表示ブロック。

§ 04量子ゲート (Operation gates)

状態ベクトルを変化させる単項 / 二項 / 制御ゲート群。すべて 40px ゲート本体 + 56px ピッチ (GATE_SIZE = 40, LINE_GAP = SLOT_SPACING = 56) に揃え、共通の hover / drag 挙動を持つ。 サイズ統一の経緯は gate-size-40px-migration.html 参照。

Hadamard (H)todo

1 量子ビット H ゲート。グリフ "H" を中央に描画。

Pauli-X / NOT (X) spec

1 量子ビット X ゲート (NOT)。cyan-400 の塗りつぶし円 + Plus (⊕) グリフを中央配置した、CNOT のターゲットと見た目を共有するゲート。
Pauli-Y (Y) spec

1 量子ビット Y ゲート。H / Z と同じ cyan-400 角丸正方形 + Geist 700 グリフ "Y"。ブロッホ球上では Y 軸まわりの 180° 回転に対応する。
Pauli-Z (Z)todo

1 量子ビット位相反転ゲート。H / Y と同じ角丸正方形 + 文字グリフの見た目を共有する。

Phase (S / T†)todo

残りの位相系列 1 量子ビットゲート (S = π/2、T† = −π/4)。T と同じ chrome を字形だけ差し替えて再利用予定。

Phase π/4 (T) spec

1 量子ビットの位相 π/4 ゲート。H / Y / Z と同じ cyan-400 角丸正方形 + Geist 700 グリフ "T"。Clifford + T で universal。
Phase −π/2 (S†) spec

S の Hermite 共役 (位相 −π/2)。S と同じ cyan-400 角丸正方形 + Geist 700 グリフ "S" の右上に小さな † を重ねて順 / 逆を字形差で示す。
Z-axis rotation (Rz) spec

1 量子ビットの Z 軸回転 (連続角 θ)。H / Y / Z / S / T と同じ cyan-400 角丸正方形 + 2 文字グリフ "Rz"。計算基底の確率を変えず相対位相だけを θ 回す、S / T / Z / P の連続版。θ は配置後にポップオーバで編集する。
Control / Anti-controltodo

制御量子ビットマーカと配線 (connector) を組で描画。

Anti-control (|0⟩ 条件) spec

Control のペア。透明な 40px 領域 + cyan-400 の空円 (r=5 / stroke=3) で |0⟩ 条件を示し、縦コネクタは空円中心 ±6px の隙間付きで分割描画する。
Swaptodo

2 量子ビット swap マーカ (× 記号) と接続線。

|0⟩ オペレーション (Reset to |0⟩) spec

対象量子ビットを |0⟩ に強制再初期化する非ユニタリ操作。cyan-400 角丸正方形は持たず、tx-2 のケット括弧 |⟩ + 中央 red-600 のディジット "0" だけで描く。
測定ゲート (Measurement) spec

Z 基底で 1 量子ビットを射影測定し、GPU 上の結果 0 / 1 を red-600 / blue-600 のディジットで重ねる非ユニタリ操作。

§ 05回路エディタ (Circuit editor)

ゲートを配置・編集する作業領域。グリッド、配線、ドラッグ / リサイズ操作、ホバー挙動などの仕様をまとめる。

Circuit gridtodo

回路本体のグリッド + 量子ビットワイヤ。40px ゲート本体を 56px ピッチで並べる。

Connectorstodo

制御線 / swap 線 / span 結合線などのコネクタ描画。

Gate hover feedbackdraft

ゲートホバー時の枠 / ハイライト挙動 (purple-400 ring + paper gap)。
Gate drag & dropdraft

パレット / 回路間のドラッグ & ドロップと配置プレビュー。

Resize handledraft

span を持つゲートのリサイズハンドル (purple-400 ピル) と挙動。

§ 06パレット / ピッカー / ツールバー

回路の周辺 UI。ゲートパレット、回路ピッカー、ツールバー、ステータス表示など。

Gate palette spec

回路エディタ上部の 2 行ゲートパレット (40 × 40 px アイコンの drag source)。
Circuit picker spec

複数回路を切り替える / 並び替える / リサイズするドロップダウン式ピッカー。
Toolbardraft

回路上部の操作ツールバー (undo / redo / trash / duplicate / run など)。
Lock / Unlock button spec

ツールバー右端のロックトグル。Example 回路の保護とユーザ意図的ロックを 1 ボタンで扱う。
GPU status pilldraft

GPU 実行状態 / フレームレートを示す右上の status pill。

§ 07状態パネル (State panel)

回路実行後の状態ベクトル / 確率分布などを表示する右側パネル。レイアウト、ポップアップ、クロムなどを別仕様としてまとめる予定。

State panel layouttodo

状態パネルのチャネル / 行 / ピッチなど寸法仕様。

State panel drawtodo

GPU 直接描画 (リードバックなし) の描画パスとシェーダ。

State panel popuptodo

状態セルホバー時の詳細ポップアップ (確率 / 振幅)。

State panel chrometodo

状態パネルの枠 / ヘッダ / フッタなどの装飾要素。

§ 09仕様ドキュメントの追加手順

新しいコンポーネントの仕様を増やすときは、以下の順で進める。

  1. docs/probability-display.html をコピーし docs/<component>.html として保存する。
  2. セクション構成 (寸法 / 配色 / 挙動 / 実装参照) は維持し、実コードの値と 1:1 で揃える。
  3. 配色は Flexoki Light のみ、フォントサイズ / 余白は Tailwind デフォルトスケールから選ぶ (AGENTS.md 参照)。
  4. ASCII アートは使わず、図は HTML/CSS または Mermaid / インライン SVG で描く。
  5. 本ファイル (docs/design-system.html) の該当カテゴリにカードを追加し、preview-mode 対応 (?preview で #preview だけ表示) を仕込んで iframe で読み込む。
