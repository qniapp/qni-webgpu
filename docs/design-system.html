デザインシステム

qni-webgpu の UI を貫く共通ルールと、画面に現れるコンポーネント仕様を一望するインデックス。 基礎トークン (配色 / タイポグラフィ / 余白) から表示ブロック、量子ゲート、回路エディタ、状態パネルまで、 寸法・色・挙動を 1 つの基準にそろえる。

§ 01基礎トークン (Foundations)

すべてのコンポーネントが共有する横断トークン (配色 / タイポグラフィ / 余白)。

配色 spec

Flexoki Light の中性色 + アクセント色一覧と、実装側 colors.rs の意味別マッピング。
タイポグラフィ spec

Geist / Geist Mono と Tailwind text-xs / text-sm / text-base スケールの使い分け。
スペーシング spec

Tailwind 4px 倍数スケール (spacing-1 = 4 / spacing-2 = 8 / …) の使い方。

§ 02Primitives (横断 UI 部品)

複数のコンポーネントが共有する小さな UI 部品 (primitive)。基礎トークンが「値」なら primitive は「部品」。 クロム (色 / 寸法 / state machine / マイクロインタラクション) を 1 箇所に集約し、各コンポーネント側は policy (使い方の差分) だけを定義する。

垂直ディバイダ spec

ゲートパレットの操作ゲート群と表示ブロック群を分ける、ui-2 の 2 px 縦区切り線。
ホバー枠 spec

対象要素に重なる purple-400 の 2px 枠。外側ホスト枠と表示セル内枠で共有。
ポップオーバー spec

セルやゲートに結び付く補足情報を表示する、tail 付き吹き出し型の共通外装。
振幅円 spec

複素値の大きさと位相を輪郭円 / 振幅円盤 / 位相針で描く、表示セル共通のプリミティブ。
リサイズハンドル spec

span を持つ表示ブロック / QFT が共有する上下ドラッグハンドル。cyan-400 ピル形 + バウンス出現。

§ 03表示ブロック (Display blocks)

回路上に「読み取り」だけを行う要素群。ユニタリ変換ではないので厳密にはゲートではなく、`表示ブロック` と呼ぶ。状態ベクトルに影響を与えず、span 内の量子ビットの確率や ブロッホベクトル等を可視化する。

確率表示ブロック spec

span 内の量子ビットを測定したときの outcome 確率を横バーで可視化する表示ブロック。
ブロッホ球表示ブロック spec

単一量子ビットのブロッホベクトル (x, y, z) を透視投影 + 矢印で可視化する表示ブロック。
振幅表示ブロック spec

span 内の量子ビットの複素振幅 (大きさ + 位相) を 1〜16 量子ビット grid で可視化する表示ブロック。
密度行列表示ブロック spec

span 内の量子ビットの局所的な混合状態 (縮約密度行列) を、対角 = 確率 + 非対角 = coupling として 2span × 2span 行列で可視化する表示ブロック。

§ 04量子ゲート (Quantum Gates)

状態に作用する単一量子ビットゲート、複数量子ビットゲート、制御マーカ、測定・リセットと、編集用の空きスロット (Spacer)。 この一覧では各要素が何をするかだけを説明し、共通の外装ルールは gate-chrome.html に委ねる。

ゲートクロム共通仕様 ref

ゲート共通の外装ルールをまとめる参照仕様。個別ゲートページはここを継承し、意味・字形・形状差分だけを書く。
Hadamard (H) spec

1 量子ビットを計算基底と重ね合わせ基底の間で変換する基本ゲート。重ね合わせを作る導入にも使う。
Pauli-X / NOT (X) spec

1 量子ビットの NOT ゲート。|0⟩ と |1⟩ を入れ替え、CNOT の対象にもなる。
Pauli-Y (Y) spec

1 量子ビットを Y 軸まわりに 180° 回転する Pauli ゲート。振幅の入れ替えと位相変化を同時に表す。
Pauli-Z (Z) spec

1 量子ビットの位相反転ゲート。|1⟩ 成分の符号を反転し、Z 軸まわりの 180° 回転に対応する。
Square-root X (√X) spec

X ゲートの平方根にあたる 1 量子ビットゲート。2 回続けて適用すると X と同じ作用になる。
S ゲート (位相 π/2) spec

1 量子ビットの位相 π/2 ゲート。|1⟩ 成分へ i を掛け、Z 軸まわりの 90° 回転に対応する。
Phase −π/2 (S†) spec

S のエルミート共役。S と逆向きの位相 −π/2 を与え、S の作用を取り消す向きに使う。
Phase π/4 (T) spec

1 量子ビットの位相 π/4 ゲート。Clifford ゲート群に加えることで普遍計算を構成する代表的な非 Clifford ゲート。
Phase −π/4 (T†) spec

T のエルミート共役。T と逆向きの位相 −π/4 を与え、T の作用を取り消す向きに使う。
Phase θ (Φ) spec

角度 θ を指定できる位相ゲート。S / T / Z などの固定角ゲートを 1 つの汎用形にまとめる。
X-axis rotation (Rx) spec

角度 θ を指定して 1 量子ビットを X 軸まわりに回転するゲート。連続的な回転操作に使う。
Y-axis rotation (Ry) spec

角度 θ を指定して 1 量子ビットを Y 軸まわりに回転するゲート。連続的な回転操作に使う。
Z-axis rotation (Rz) spec

角度 θ を指定して 1 量子ビットを Z 軸まわりに回転するゲート。連続的な位相操作に使う。
Control (|1⟩ 条件) spec

同じ列の対象ゲートを |1⟩ 条件で実行する制御マーカ。多量子ビット操作の条件を表す。
Anti-control (|0⟩ 条件) spec

同じ列の対象ゲートを |0⟩ 条件で実行する制御マーカ。通常の制御とは逆の条件を表す。
Swap spec

2 つの量子ビットの状態を交換する操作ゲート。ペアで置かれた対象同士を入れ替える。
QFT (量子フーリエ変換) spec

複数量子ビットへ量子フーリエ変換を適用する操作ゲート。作用範囲を指定して使う。
QFT† (逆量子フーリエ変換) spec

量子フーリエ変換の逆変換を適用する操作ゲート。QFT と同じく作用範囲を指定して使う。
|0⟩ オペレーション (Reset to |0⟩) spec

対象量子ビットを |0⟩ に強制再初期化する非ユニタリ操作。回路内で値をリセットする。
|1⟩ オペレーション (Reset to |1⟩) spec

対象量子ビットを |1⟩ に強制再初期化する非ユニタリ操作。回路内で値をリセットする。
測定ゲート (Measurement) spec

Z 基底で 1 量子ビットを射影測定する非ユニタリ操作。測定結果に応じて状態を収縮させる。
Spacer ゲート (空きスロット) spec

状態に作用しない空きスロット。回路の列間隔や読みやすさを調整するために使う。

§ 05回路エディタ (Circuit editor)

ゲートを配置・編集する作業領域。グリッド、配線、ドラッグ / リサイズ操作、ホバー挙動などの仕様をまとめる。

Circuit gridtodo

回路本体のグリッドと量子ビットワイヤ。ゲートを配置する編集面の基準を定義する。

Connectorstodo

制御線 / swap 線 / span 結合線などのコネクタ描画。

Gate drag & dropdraft

パレット / 回路間のドラッグ & ドロップと配置プレビュー。

§ 06パレット / ピッカー / ツールバー

回路の周辺 UI。ゲートパレット、回路ピッカー、ツールバー、ステータス表示など。

Gate palette spec

回路エディタ上部のゲートパレット。配置できるゲートを選び、回路へドラッグする。
Circuit picker spec

複数回路を切り替える / 並び替える / リサイズするドロップダウン式ピッカー。
Toolbardraft

回路上部の操作ツールバー (undo / redo / trash / duplicate / run など)。
Lock / Unlock button spec

ツールバー右端のロックトグル。Example 回路の保護とユーザ意図的ロックを 1 ボタンで扱う。
GPU status pilldraft

GPU 実行状態 / フレームレートを示す右上の status pill。

§ 07状態パネル (State panel)

回路実行後の状態ベクトル / 確率分布などを表示する右側パネル。レイアウト、ポップアップ、クロムなどを別仕様としてまとめる予定。

State panel layouttodo

状態パネルのチャネル / 行 / ピッチなど寸法仕様。

State panel drawtodo

GPU 直接描画 (リードバックなし) の描画パスとシェーダ。

State panel popuptodo

状態セルホバー時の詳細ポップアップ (確率 / 振幅)。

状態パネルクロムtodo

状態パネルの枠 / ヘッダ / フッタなどの装飾要素。

§ 09仕様ドキュメントの追加手順

新しいコンポーネントの仕様を増やすときは、以下の順で進める。

  1. docs/design-system/probability-display.html をコピーし docs/design-system/<component>.html として保存する。
  2. セクション構成 (寸法 / 配色 / 挙動 / 実装参照) は維持し、実コードの値と 1:1 で揃える。
  3. 配色は Flexoki Light のみ、フォントサイズ / 余白は Tailwind デフォルトスケールから選ぶ (AGENTS.md 参照)。
  4. ASCII アートは使わず、図は HTML/CSS または Mermaid / インライン SVG で描く。
  5. 本ファイル (docs/design-system.html) の該当カテゴリにカードを追加し、preview-mode 対応 (?preview で #preview だけ表示) を仕込んで iframe で読み込む。
