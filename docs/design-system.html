デザインシステム

qni-webgpu の UI コンポーネント仕様 (寸法 / 配色 / 挙動 / 実装参照) を 1 つにまとめたインデックス。 各カードは個別の仕様ドキュメント (docs/<component>.html) にリンクしており、 probability-display.html をテンプレートとして同じ構造で増やしていく。 配色は Flexoki Light、タイポ / 余白は Tailwind デフォルトスケールに厳密に合わせる。

§ 01表示ブロック (Display blocks)

回路上に「読み取り」だけを行う要素群。ユニタリ変換ではないので厳密にはゲートではなく、`表示ブロック` と呼ぶ。状態ベクトルに影響を与えず、span 内 量子ビットの確率や ブロッホベクトル等を可視化する。

確率表示ブロック spec

span 内 量子ビットを測定した場合の outcome 確率を可視化。span 1〜4 は横バー + XX.X% ラベル、span 5〜16 はバー主体 (省ラベル + 対数ヒント線)。ホバー時に raw / log 詳細をポップアップ表示。

Probability · probability_display.rs
ブロッホ球表示ブロック spec

単一 量子ビットの ブロッホベクトル (x, y, z) を透視投影 + 矢印で可視化。span 1 固定、GPU reduce → overlay でリードバックなし。

Bloch · bloch_display.rs
振幅表示ブロック spec

span 内 量子ビットの複素振幅 (大きさ + 位相) を可視化する表示ブロック。state panel と同じ 3 層 (outline 円 + blue-200 disk + tx needle) を 1〜16 量子ビット grid に並べる。位相 0 = 真上。Quirk AmplitudeDisplayFamily の WebGPU 移植仕様。

Amps · amplitude.rs
密度行列表示ブロック todo

部分系の密度行列をヒートマップとして表示する表示ブロック。

§ 07仕様ドキュメントの追加手順

新しいコンポーネントの仕様を増やすときは、以下の順で進める。

  1. docs/probability-display.html をコピーし docs/<component>.html として保存する。
  2. セクション構成 (寸法 / 配色 / 挙動 / 実装参照) は維持し、実コードの値と 1:1 で揃える。
  3. 配色は Flexoki Light のみ、フォントサイズ / 余白は Tailwind デフォルトスケールから選ぶ (AGENTS.md 参照)。
  4. ASCII アートは使わず、図は HTML/CSS または Mermaid / インライン SVG で描く。
  5. 本ファイル (docs/design-system.html) の該当カテゴリにカードを追加し、ステータスを spec に上げる。
