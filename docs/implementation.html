実装仕様

デザインシステムから分離した実装仕様のインデックス。 WebGPU パイプライン、外部バックエンド連携、バッファ形式、参照ファイル、受け入れ条件など、見た目以外の実装上の約束をまとめる。

§ 01ドメインモデル

value object CircuitColumnIndex 実装仕様

回路上の 0 始まり列番号を値オブジェクトとして扱うための仕様。

 value object ParametricAngle 実装仕様

P / Rx / Ry / Rz の角度を値オブジェクトとして扱うための仕様。

 value object QubitCount 値オブジェクト 実装仕様

量子ビット数、ローカル上限 16、外部 GPU 上限 32 を値オブジェクトとして扱う方針。

 value object ColumnControls 実装仕様

列の制御条件（control / anti-control のビットマスク対）を 1 つの値オブジェクトにまとめる方針。

 value object WireIndex 実装仕様

回路エディタのワイヤ番号を値オブジェクト化し、MSB 始まりビット番号への変換を集約する方針。

 value object QubitBit 実装仕様

GPU の MSB 始まりビット番号を値オブジェクト化し、1u32 << bit のマスク生成を集約する方針。

 value object GateSpan 実装仕様

ゲートの縦スパンを値オブジェクト化し、1 以上の不変条件と種類別上限の切り詰めを集約する方針。

 value object GateId 実装仕様

ゲートの同一性 id: u32 を値オブジェクト化し、一意な採番を GateIdAllocator へ集約する方針。

 value object CircuitId 実装仕様

回路ライブラリのエントリ識別子を型エイリアスから非空 newtype へ昇格する方針。

 value object Shots 実装仕様

外部 GPU 実行の測定ショット数を値オブジェクト化し、バックエンド契約と同じ範囲を Rust 側で保証する方針。

 value object SlotIndex 実装仕様

GPU バッファのスロット番号を家族ごとに型分けし、家族の取り違えと採番を型で防ぐ方針。

 value object ProbabilityDistribution 実装仕様

外部 GPU（Qiskit）から受け取る測定確率分布を値オブジェクト化し、長さ・値域・有限性を取り込み境界で検証する方針。
