# 事後選択

事後選択は、指定した状態への射影によって、条件を満たす試行だけを残す操作である。
量子ビットへの書き込みや、結果を無作為に選ぶ測定とは異なる。

## 対応するゲート

| コード識別子 | 残す状態 | Quirk 互換の保存 ID |
| --- | --- | --- |
| `PostSelectOff` | `\|0⟩` | `\|0⟩⟨0\|` |
| `PostSelectOn` | `\|1⟩` | `\|1⟩⟨1\|` |
| `PostSelectAntiX` | `\|+⟩` | `\|+⟩⟨+\|` |
| `PostSelectX` | `\|−⟩` | `\|-⟩⟨-\|` |

保存 ID のマイナスは ASCII の `-` を使う。
内部識別子の `AntiX` は歴史的な名前であり、画面では残す状態を `+` と表示する。
URL と回路 JSON は同じ保存 ID を使う。

## 条件付き状態と生存率

GPU が射影を適用し、残った振幅の絶対値の二乗和を計算する。
その値がこのゲートでの受理確率であり、振幅を受理確率の平方根で割ることで条件付き状態を正規化する。
ブロッホ球・確率・振幅・密度行列の表示ブロックと状態ベクトルパネルは、この条件付き状態を表示する。

生存率は、それまでの受理確率の積として別の GPU バッファに保持する。
表示は Quirk に合わせ、事後選択を含む各列の下に、直前の列までの累積生存率に対する増減率を示す。
増減率は `(列の生存率 − 直前の生存率) / 直前の生存率` で求め、最初の列の直前は 1 とする。
減少は `omits`、増加は `gains` とし、割合をその下の行に赤色で表示する。
同じ列に複数の事後選択があっても表示は一つである。
増減率が未定義、または絶対値が 0.005 以下なら表示しない。
`omits` の割合は減少分を整数の百分率に丸め、完全にゼロになった場合は `100%`、ゼロでないのに丸めると 100% になる場合は `>99%` とする。
`gains` の割合は増減率に 1 を足した値を整数の百分率に丸める。

回路全体の累積生存率は、状態ベクトルパネルの下端付近に赤色の `kept: N%` として一度だけ表示する。
1 との差の絶対値が 0.01 以下なら表示しない。
`N` は整数に丸めた百分率とし、生存率が `1e-12` 以下なら `0`、それより大きくても丸めると 0 になる場合は `<1` とする。
列の選択による状態のプレビュー中も、生存率の表示は回路全体に対する値を維持する。
増減率の計算、表示する文字の選択、描画も GPU が行い、状態や生存率を本番の描画経路で CPU に読み戻さない。
例えば、`H` の後に `|0⟩⟨0|` を置くと、条件付き状態は `|0⟩`、列の表示は `omits` と `50%`、全体の表示は `kept: 50%` になる。
さらに `H` と `|+⟩⟨+|` を続けても、その列では生存率が変わらないため列には表示が出ず、`kept: 50%` のままとなる。

受理確率が `1e-12` 以下の場合は、数値的にゼロとして扱う。
このとき条件付き状態は未定義であり、状態バッファをゼロにして後続の表示を空表示または未定義表示にする。
ゼロの状態を正規化したり、前の計算結果を表示し続けたりしない。
後続の測定も結果を持たず、結果の数字は表示せず、その結果を条件とする古典制御は適用しない。
生存率が小さいことだけを理由に、正規化できる条件付き状態を未定義にはしない。

## 実行方式

ローカル WebGPU 計算に対応する。
外部 Qiskit 実行では未対応ゲートとして実行前に拒否し、射影を通常のユニタリゲートに置き換えない。

Quirk の `PostSelectionGates.js`、`CircuitStats.js`、`DisplayedCircuit.js` を意味論の参照元とし、実装コードは転用しない。
