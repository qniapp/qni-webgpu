ゲートラベルのフォント案

chrome (塗り色・ボーダー・角丸・サイズ) は現状のままで触らない。 cyan-400 のユニタリ箱、paper 文字、tx-2 の control / swap アイコン、 red-600 / blue-600 の Write0 / Write1 ブラケット — すべて Flexoki Light の現行マッピング通り。

差し替えの対象は 文字グリフ 15 個: H + Y Z √X S S† T T† P RX RY RZ QFT QFT†。 ゲートの形は icons.rs と一致させる: X と P は丸、それ以外は角丸正方形。 X の中身は + (CNOT target の慣習)、P は P 一文字、 Rx/Ry/Rz は 32 px ボックスで subscript が読めないので R+大文字 X / Y / Z を並べる icons.rs の流派を踏襲。

Swap / Control / AntiControl / Bloch 球 / Measurement / Write |0⟩ / Write |1⟩ / Spacer はグラフィカルに描く側のゲートなので、ここでは扱わない (それらは現状の SVG ベクター描画のまま)。

どの案も同じ chrome の上に同じレイアウトで上記 15 ゲートを Pauli / Phase & Roots / Rotations / QFT family に分けて並べてある。 差分はフォント family と weight、わずかな size / letter-spacing の調整のみ。

サイズは実アプリと完全一致: GATE_SIZE = 32 px ・ corner radius 6 px ・ PALETTE_GAP = 8 px。 モニタ越しに見えるそのまま (DPR 100%) が、回路に配置されたときのゲートの 実寸サイズなので、視認性 / 字面の潰れ / 縦棒の細さ等を直接判断できる。
