ゲートラベルのフォント案

chrome (塗り色・ボーダー・角丸・サイズ) は現状のままで触らない。 cyan-400 のユニタリ箱、paper 文字、tx-2 の control / swap アイコン、 red-600 / blue-600 の Write0 / Write1 ブラケット — すべて Flexoki Light の現行マッピング通り。

差し替えの対象は H X Y Z √X S S† T T† P Rx Ry Rz QFT QFT† |0⟩ |1⟩ といった文字グリフ だけ。 Bloch 球 / Measurement の計器 / Control の点 / AntiControl の白丸 / Swap の × / Spacer の ⋯ は 記号 / アイコンで現状の SVG パスをそのまま流用する。

どの案も同じ chrome の上に同じレイアウトで 23 ゲート全部 を Pauli / Phase & Roots / Rotations / Control / Display & I/O に分けて並べてある。 差分はフォント family と weight、わずかな size / letter-spacing 調整のみ。
