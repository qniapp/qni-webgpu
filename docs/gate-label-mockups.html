ゲートラベルのデザイン案

現在のゲートアイコンは qni の SVG パスを座標ごと書き写したベクター線。これをよりモダンな方向で見直すための 4 案。 各案で 23 個すべてのゲート (Pauli 系 / 平方根・位相 / パラメトリック回転 / control & swap / 表示 & 初期化) を並べて比較できるようにしてある。

フォントはすべて Google Fonts から読み込み (JetBrains Mono / Inter / Newsreader / STIX Two Text / Public Sans)。 Bloch 球 / 測定計のアイコンは現状の qni 移植を簡略化して inline SVG で再現。色は Flexoki Light トークンの範囲内で割り当てている。
