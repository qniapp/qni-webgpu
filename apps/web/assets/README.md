# Font assets

- `Geist-*.ttf`: Geist Sans by Vercel, SIL Open Font License 1.1.
- `GeistMono-Regular.ttf`: Geist Mono by Vercel, SIL Open Font License 1.1.
- `QniJapaneseFallback-Regular.otf`: CP932/JIS subset generated from Noto Sans CJK JP Regular by Google / Adobe, SIL Open Font License 1.1. The generated subset uses QNI-specific names and is only used as an egui fallback so Japanese circuit names render instead of tofu.
